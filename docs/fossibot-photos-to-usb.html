What you need

A FOSSiBOT F-series Android phone (Android 7.0 or later for SnapDisk) — the F101 Pro and the F101P run Android 13, the F102 runs Android 13, and the F107 Pro and the F113 run Android 15 — so a USB-C flash drive plugs straight into any of them, while a regular USB-A drive needs a USB-C OTG adapter — and enough space on the drive for the photos you want to keep. Three FOSSiBOT specifics: first, OTG is confirmed on most of the line — the spec tables list USB OTG as Yes for the F101, the F101 PRO, the F102, the F110 Pro 5G, and the F113, the F112 Pro's spec page lists USB OTG Type-C, and the F107 Pro's official-site spec says you can connect USB flash drives via an OTG cable — but the F101P's official page mentions OTG only as reverse charging and the F115 Ultra's spec data conflicts, so plug a drive in and check Settings > Storage before relying on it on those two models. Second, FOSSiBOT has no phone-to-USB backup tool of its own — its backup advice is a computer copy or Google Drive and Google Photos; the stock photo backup is Google Photos; the stock file manager is Files by Google; FOSSiBOT camera photos live in DCIM/Camera, as on any Android phone. The F101 Pro takes a microSD card up to 1 TB, and the F107 Pro and the F113 take one up to 2 TB — the F102's card size is the one disagreement in my sources, 1 TB per RottenWifi and 2 TB per Cashify — so a card is an option, and it still stays in the phone and opening it anywhere else needs a card reader, while a USB drive plugs into any computer as it is. Third, SnapDisk installs from the v0.1.2 APK on the GitHub release page today and from Play once the listing is live. One format note: drives formatted FAT32 can't hold a single file over 4 GB. That only matters for very long videos — SnapDisk skips those files and lists them instead of failing the whole backup. A drive formatted exFAT has no such limit.

Method 1: SnapDisk (one tap, background copy)

SnapDisk is a free Android app that does exactly this job and nothing else. Install it from the v0.1.2 APK (it's not on Google Play yet), then:

  1. Plug in the USB drive. It mounts on plug-in on most FOSSiBOT Android phones — look for a "USB storage added" notification. If nothing appears, check Settings > Storage for the drive. OTG is listed as Yes for the F101, the F101 PRO, the F102, the F110 Pro 5G, and the F113, the F112 Pro lists USB OTG Type-C, and the F107 Pro's official-site spec names flash drives over an OTG cable, so the drive should appear on them; on the F101P and the F115 Ultra, whose OTG host support is unlisted or conflicting, check Settings > Storage to confirm the drive mounted.
  2. Open SnapDisk and check the folders. The app opens to a settings screen with a From folder and a To folder, each with a folder picker. The defaults are already right for most people: From /sdcard/DCIM (your camera photos — FOSSiBOT camera photos live in DCIM/Camera), To /disk/DCIM on the drive. If your photos live somewhere else, tap the From picker and choose that folder — the picker is the Android system folder picker, and the app keeps access to it.
  3. Tap Backup. SnapDisk offers a backup in a notification when the drive connects: "External storage is connected. Backup photos?" Tap it and your whole library copies oldest-first — your earliest photos first — in the background, while you use the phone normally. The copy mirrors the source folder structure on the drive, so DCIM stays DCIM.
  4. Watch the progress notification — real percent, copied / total size, speed, and time left — with Pause and Stop. You can pause and resume any time.
  5. Wait for "Backup complete." Every file is size-verified after copying, so the counts are proof, not a promise. Files that already copied are never copied twice — so if the free 5 GB per-run limit stops a big library partway, just run it again and it picks up where it left off.

The copies are the original files. SnapDisk streams each file byte-for-byte from the phone to the drive — the code reads the file and writes the same bytes out, with no decode, no recompression, and no resize — and then checks that the copy on the drive is the same size as the original. Other apps copy originals byte-for-byte too; what SnapDisk adds is the automated whole-library run: oldest-first order, progress with Pause and Stop, resume where it stopped, and skip-if-already-copied on the next run. If a file is corrupt or too big for FAT32, it's retried once, then skipped with its reason listed — it never stalls the whole backup. The free version backs up manually, up to 5 GB per backup run, with no ads, no account, and no cloud. Method 2: a file manager (the stock route, no app needed)

A file manager can copy your photos to the USB drive — the YouTube guides' route is an OTG adapter copy, and askfilo's route is the same, and either is the manual route for external storage: 1. Plug in the USB drive — a notification should appear saying "USB storage added"; tap it to open the drive. If nothing appears, check Settings > Storage for the drive. 2. Open the file manager (Files by Google on FOSSiBOT phones) and confirm the USB drive shows up under storage devices. 3. Go back to Internal storage, DCIM, Camera, where your camera photos live. 4. Select the photos (long-press the first, tap the rest, or select all). 5. Tap Copy, then select the USB drive, and wait for the copy to finish — don't unplug the drive until the file manager says it's done. Eject the drive from the notification or from Settings > Storage before unplugging it. Use Copy, not Move: Move deletes the originals as it goes, so a bumped cable halfway through loses photos. This works fine for a one-off copy. Its limits are the reason SnapDisk exists: you pick files one by one, there is no progress detail beyond a spinner, no resume if you unplug mid-copy, no verification that every file actually arrived, and you have to repeat the whole manual selection next time photos pile up. For a library that grows every day, the app's oldest-first background copy is the calmer option.

What this does not do

A few honest limits, so the automatic copy is not oversold:

  • Photos and videos only. SnapDisk copies image and video files. Documents, voice notes, and anything that isn't a photo or video is skipped — Google backup is the tool if you want contacts, messages, and settings in the same backup, not just photos.
  • Only the folder you pick. By default that's DCIM — your camera photos. Photos in other folders (Downloads, app folders) only copy if you point the From folder at them, or at a parent folder that contains them.
  • Free 5 GB per run. A library bigger than 5 GB stops at the cap; run it again and it picks up where it stopped. Pro ($9.99, one-time) removes the limit and starts the backup automatically when you plug in a disk.
  • Files over 4 GB on FAT32 are skipped. Very long videos on a FAT32 drive are listed with their reason instead of failing the backup. Reformat the drive to exFAT if you need them.
  • It never deletes. SnapDisk only copies. Freeing space on the phone is copy, check the copy on the drive, then delete the originals yourself — never the other way round.
  • OTG is not confirmed on every FOSSiBOT model. The spec tables list USB OTG as Yes for the F101, the F101 PRO, the F102, the F110 Pro 5G, and the F113, the F112 Pro's spec page lists USB OTG Type-C, and the F107 Pro's official-site spec says you can connect USB flash drives via an OTG cable — but the F101P's official page mentions OTG only as reverse charging, which powers another device and is not hosting a drive, and the F115 Ultra's spec data conflicts (one source lists USB OTG as false while also listing USB-C as false), so confirm the drive mounts in Settings > Storage on those two models before relying on it. SnapDisk still needs Android 7.0 or later.
  • The oldest FOSSiBOT phone is out of scope until checked. The original F101 went on sale in October 2020, and I did not verify its Android version in the sources above, so owners of that model should check Settings > About phone first — SnapDisk needs Android 7.0 or later and cannot install on anything older. Every other F-series model I found runs Android 13 or 15.

What to avoid

  • Buying an adapter you don't need — or the wrong one. A USB-C flash drive plugs straight into the F101, the F101 Pro, the F102, the F107 Pro, the F110 Pro 5G, the F112 Pro, and the F113, which all have USB-C — so an adapter is only needed for a regular USB-A drive, and it must be a USB-C OTG adapter, not a micro-USB one. A plain USB-C charging cable is not an OTG adapter: it connects the phone to a computer, which is the opposite direction.
  • Mistaking a cloud backup for a photo copy. Google Drive and Google Photos back your phone up to Google's servers — if you want to plug the drive into a computer and open the pictures, you need a plain copy, that is Method 1 or 2, not a cloud backup.
  • Mistaking a PC tool for a phone-to-USB copy. FOSSiBOT's own backup advice is a computer copy with a USB cable and a file browser — but it is a copy to a computer, and the backup lands on the PC. If the phone and the drive are all you have, a phone-to-USB copy is the route, not a desktop copy.
  • Mistaking a spec table or a user manual for a phone-to-USB guide. The F107 Pro manual page and the F102 FAQ page are real FOSSiBOT pages — but the manual only mentions OTG as reverse charging ("10W OTG reverse charging, allowing you to power other devices"), and the FAQ only says to connect the phone to a computer and copy the files with a file browser. Neither of them describes copying your camera roll straight to a USB drive from the phone.
  • Mistaking "OTG reverse charging" for OTG host support. The F101P's official page and the F107 Pro manual both mention OTG reverse charging — that is the phone sharing its battery with another device, not the phone reading a flash drive. The host evidence for the F107 Pro is the official-site spec saying flash drives connect via an OTG cable; for the F101P there is no host evidence at all, so test with a drive.
  • Mistaking a microSD card copy for a USB backup. Copying DCIM to a microSD card is a real local copy — the F101 Pro takes a card up to 1 TB, and the F107 Pro and the F113 take one up to 2 TB — but the card stays in the phone, and opening it anywhere else needs a card reader; a USB drive plugs into any computer as it is.
  • PC-only tools when you have no computer. Drag-and-drop through a Windows PC works — but it needs the PC in between. If the phone and the drive are all you have, a phone-to-USB copy is the route — that is the gap this article fills, as of November 18, 2026.
  • Cloud backup dressed as USB backup. If the app needs an account and an upload before your photos are safe, that's a cloud subscription with a USB step. Your photos sit on someone else's server, and the backup stops working the day you stop paying. On FOSSiBOT the cloud routes are Google Photos and Google Drive — and Google Photos' "Storage saver" setting compresses photos, which is the one place quality actually gets lost.
  • Installing SnapDisk on a FOSSiBOT that is too old to run it. The original F101 went on sale in October 2020 and its Android version is unverified in my sources — SnapDisk needs Android 7.0 or later. Check Settings > About phone before installing on that model; every other F-series model I found runs Android 13 or 15.
  • Deleting before verifying. A backup is only a backup once you've confirmed the copy. Copy, open a few photos on the drive, then delete from the phone — never the other way round. SnapDisk only copies — it never deletes — so the delete step is always yours, and always after the check.
  • Moving instead of copying. The file manager's Move option copies and then deletes the originals in one step. If the copy fails halfway, photos are already gone from the phone. Copy first, verify, then delete.
  • Unplugging mid-copy. Pulling a USB drive out while files are still writing can corrupt the file in flight. Wait for the copy to finish, or pause it first — SnapDisk's Stop button exists for exactly this.

Rule of thumb: if you have to pick the files yourself, it isn't a backup — it's a chore you will skip. Automate the copy, check it on the drive, then delete from the phone.
