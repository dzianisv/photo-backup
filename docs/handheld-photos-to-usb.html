Method 1: SnapDisk (one tap, background copy)

SnapDisk is a free Android app that does exactly this job and nothing else. Install it from the v0.1.2 APK (it's not on Google Play yet), then:

  1. Check your model can run SnapDisk. The refreshed X2 runs Android 9.0 GMS, the X6 runs Android 8.0 (8.1 in one review), the X9 runs Android 7.0 (Android 11 in a later press release), the X41 runs Android 9.0 GMS, and the X81 runs Android 12 GMS — all clear the Android 7.0 minimum, so SnapDisk installs on all five. The original X2 runs Android 6.0, the X4 runs Android 4.2 or Windows, and the X8 runs Android 4.2.2 or Windows — none of those three can run SnapDisk, and Method 4 is the route on them. If you are unsure which generation your X2 is, check Settings > About phone: Android 6.0 is the original, Android 9.0 is the refreshed one.
  2. Plug in the USB drive. On the X81 a standard USB-A flash drive plugs straight into the USB A host port on the bottom panel — no adapter is needed at all. On the refreshed X2 and the X9, connect the drive with a micro-USB OTG adapter. On the X6 and the X41, connect it with a USB-C OTG adapter. A dual drive with the matching end (micro-USB for the X2 and X9, USB-C for the X6 and X41) plugs straight in with no adapter. It mounts on plug-in on most Android devices with USB host support — look for a "USB storage added" notification. If nothing appears, check Settings > Storage for the drive.
  3. Open SnapDisk and check the folders. The app opens to a settings screen with a From folder and a To folder, each with a folder picker. The defaults are already right for most people: From /sdcard/DCIM (your camera photos — Nautiz camera photos live in DCIM/Camera), To /disk/DCIM on the drive. If your photos live somewhere else, tap the From picker and choose that folder — the picker is the Android system folder picker, and the app keeps access to it.
  4. Tap Backup. SnapDisk offers a backup in a notification when the drive connects: "External storage is connected. Backup photos?" Tap it and your whole library copies oldest-first — your earliest photos first — in the background, while you use the handheld normally. The copy mirrors the source folder structure on the drive, so DCIM stays DCIM.
  5. Watch the progress notification — real percent, copied / total size, speed, and time left — with Pause and Stop. You can pause and resume any time.
  6. Wait for "Backup complete." Every file is size-verified after copying, so the counts are proof, not a promise. Files that already copied are never copied twice — so if the free 5 GB per-run limit stops a big library partway, just run it again and it picks up where it left off.

The copies are the original files. SnapDisk streams each file byte-for-byte from the handheld to the drive — the code reads the file and writes the same bytes out, with no decode, no recompression, and no resize — and then checks that the copy on the drive is the same size as the original. Other apps copy originals byte-for-byte too; what SnapDisk adds is the automated whole-library run: oldest-first order, progress with Pause and Stop, resume where it stopped, and skip-if-already-copied on the next run. If a file is corrupt or too big for FAT32, it's retried once, then skipped with its reason listed — it never stalls the whole backup. The free version backs up manually, up to 5 GB per backup run, with no ads, no account, and no cloud. SnapDisk Pro is a one-time $9.99 purchase (no subscription) that starts the backup automatically when you plug in a disk and removes the size limit. The app has no internet permission, so your photos physically cannot leave your handheld.

Method 2: a file manager (the stock route, no app needed)

A file manager can copy your photos to the USB drive — the generic guides' route is an OTG connection with the built-in file manager, and it is the manual route for external storage: 1. Plug in the USB drive — on the X81 a standard USB-A drive plugs straight into the USB A host port on the bottom panel, no adapter needed; on the refreshed X2 and the X9 use a micro-USB OTG adapter, and on the X6 and the X41 use a USB-C OTG adapter. A notification should appear saying "USB storage added"; tap it to open the drive. If nothing appears, check Settings > Storage for the drive. 2. Open the file manager and confirm the USB drive shows up under storage devices. 3. Go back to Internal storage, DCIM, Camera, where your camera photos live. 4. Select the photos (long-press the first, tap the rest, or select all). 5. Tap Copy, then select the USB drive, and wait for the copy to finish — don't unplug the drive until the file manager says it's done. Eject the drive from the notification or from Settings > Storage before unplugging it. Use Copy, not Move: Move deletes the originals as it goes, so a bumped cable halfway through loses photos. This works fine for a one-off copy. Its limits are the reason SnapDisk exists: you pick files one by one, there is no progress detail beyond a spinner, no resume if you unplug mid-copy, no verification that every file actually arrived, and you have to repeat the whole manual selection next time photos pile up. For a library that grows every day, the app's oldest-first background copy is the calmer option. One note: no source found names the stock file manager on a Nautiz handheld — the steps above use the built-in file manager, whatever it is called on your unit.

Method 3: Handheld's own tools (Google Photos, Google Drive, MaxGo, or a microSD card — not phone-to-USB)

If you want Handheld's own route, know what each tool actually does — there is no Handheld backup page pointing at a USB drive at all, and none of the stock tools writes your photos as plain files to a USB drive automatically. 1. Google Photos is Google's own photo backup app, and it is the stock photo backup on GMS Android handhelds like the Nautiz line: it automatically backs up photos to your Google account. It is a real backup — but it is a cloud backup, not a USB copy, and photos sync through Google Photos instead. 2. Google Drive is the cloud backup Android names by default — "on Android devices the default built-in service is Google Drive. With Google Drive you have 15Gb free" — it backs your data up to Google's cloud. It is a real backup — but it is a cloud backup, not a USB copy, and Google accounts only offer 15 GB of free storage. 3. Google backup is what Android itself names: personal settings back up to Google's servers with a Google account, and are restored to a new phone when you sign in with that account. It is a real backup — but it backs up settings, not a folder of photo files on a drive you hold. 4. The MaxGo suite is Handheld's own Android app suite — it "allows easy configuration of staging and security settings" on Nautiz devices. It is a real Handheld tool — but it is device management and staging, not a photo backup, and it does not copy your camera roll to a USB drive. 5. A microSD card is the local option on every covered model — the refreshed X2 takes a card up to 256 GB, the X6 and the X41 up to 128 GB, and the X9 up to 32 GB. It is a real local copy — but the card stays in the device, and opening the card anywhere else needs a card reader. 6. A computer copy is the other way to move files off the handheld — connect the device to a computer with a USB cable and copy DCIM from the device to the computer. It is a real backup — but it needs a PC in between, and the backup lands on the PC, not on a USB drive as plain files straight from the device. None of them is a one-tap way to copy your camera roll to a drive. All of them work fine for what they are. Their limit, for photos specifically: none of them gives you a folder of plain photo files on a USB drive you can plug into any computer and open. If what you want is a copy of your photos you can open anywhere, Method 1 or 2 is the route — that is the gap this article fills, as of November 18, 2026.

Method 4: through a computer (if you have one)

If a PC or Mac is handy, the old route still works: plug the handheld into the computer with a USB cable, tap the USB notification and choose File transfer — and drag the DCIM folder onto the USB drive. This works fine, and it is the only route above that needs a second device in between. It is also the only route that works at all on the original X2, the X4 and the X8, which cannot run SnapDisk. If the handheld and the drive are all you have, Method 1 or 2 is the route — that is the gap this article fills, as of November 18, 2026.

What this does not do

A few honest limits, so the automatic copy is not oversold:

  • Photos and videos only. SnapDisk copies image and video files. Documents, voice notes, and anything that isn't a photo or video is skipped — Google backup is the tool if you want contacts, messages, and settings in the same backup, not just photos.
  • Only the folder you pick. By default that's DCIM — your camera photos. Photos in other folders (Downloads, app folders) only copy if you point the From folder at them, or at a parent folder that contains them.
  • Free 5 GB per run. A library bigger than 5 GB stops at the cap; run it again and it picks up where it stopped. Pro ($9.99, one-time) removes the limit and starts the backup automatically when you plug in a disk.
  • Files over 4 GB on FAT32 are skipped. Very long videos on a FAT32 drive are listed with their reason instead of failing the backup. Reformat the drive to exFAT if you need them.
  • It never deletes. SnapDisk only copies. Freeing space on the handheld is copy, check the copy on the drive, then delete the originals yourself — never the other way round.
  • OTG or host is confirmed only for the five covered models. The refreshed X2 and the X9 list OTG on micro-USB, the X6 and the X41 list OTG on USB-C, and the X81 has a USB A host port — but the original X2's datasheet lists no OTG at all, and the X4's USB host exists only for the Ethernet cradle. The refreshed X2 and the X9 need a micro-USB OTG adapter, and the X6 and the X41 need a USB-C OTG adapter — a micro-USB adapter does not fit a USB-C port, and a USB-C adapter does not fit a micro-USB port.
  • Assuming your X2 is the refreshed one. The X2 is two generations under one name — Android 6.0 with no OTG listed in the original datasheet, Android 9.0 GMS with OTG in the refreshed datasheet. Check Settings > About phone before buying an adapter or installing SnapDisk: on the original X2, neither works.
  • Assuming the X8 hosts drives for SnapDisk because its manual lists a USB A Host port. The X8 does list a USB A Host port — but it runs Android 4.2.2 or Windows Embedded Handheld 6.5.3, so SnapDisk cannot install on it, and the host port does not help. Method 4 is the route on the X8.
  • Assuming one Android version belongs to one model. The X6 is Android 8.0 in its datasheet and Android 8.1 in a review; the X9 is Android 7.0 in its datasheet and Android 11 in a later press release — check Settings > About phone on your unit instead of trusting a version printed for another source.
  • Mistaking a cloud backup for a photo copy. Google Drive and Google Photos back your handheld up to Google's servers — if you want to plug the drive into a computer and open the pictures, you need a plain copy, that is Method 1 or 2, not a cloud backup.
  • Mistaking a PC tool for a phone-to-USB copy. A computer copy with a USB cable moves files to a computer — but it is a copy to a computer, and the backup lands on the PC. If the handheld and the drive are all you have, a phone-to-USB copy is the route, not a desktop copy.
  • Mistaking a spec sheet or a datasheet for a phone-to-USB guide. The Handheld datasheets are real Handheld documents — but they only list an Android version, a processor, a camera, or a USB port type. None of them describes copying your camera roll straight to a USB drive from the handheld.
  • Mistaking MaxGo for a photo backup. The MaxGo suite is a real Handheld tool — but it configures staging and security settings, it does not copy your camera roll to a USB drive.
  • Mistaking a drive-locked app for a general backup. Photo Backup Stick DC is a real one-tap backup app — but it only works with genuine Photo Backup Stick OTG drives. If the drive you already own is any other brand, that app cannot use it: SnapDisk, Photos to USB, and FotoSafe work with any drive.
  • Mistaking a microSD card copy for a USB backup. Copying DCIM to a microSD card is a real local copy — the refreshed X2 takes a card up to 256 GB, the X6 and the X41 up to 128 GB, the X9 up to 32 GB — but the card stays in the device, and opening it anywhere else needs a card reader; a USB drive plugs into any computer as it is.
  • PC-only tools when you have no computer. Drag-and-drop through a Windows PC works — but it needs the PC in between. If the handheld and the drive are all you have, a phone-to-USB copy is the route — that is the gap this article fills, as of November 18, 2026.
  • Cloud backup dressed as USB backup. If the app needs an account and an upload before your photos are safe, that's a cloud subscription with a USB step. Your photos sit on someone else's server, and the backup stops working the day you stop paying. On a Nautiz handheld the cloud routes are Google Photos and Google Drive — and Google Photos' "Storage saver" setting compresses photos, which is the one place quality actually gets lost.
  • Deleting before verifying. A backup is only a backup once you've confirmed the copy. Copy, open a few photos on the drive, then delete from the handheld — never the other way round. SnapDisk only copies — it never deletes — so the delete step is always yours, and always after the check.
  • Moving instead of copying. The file manager's Move option copies and then deletes the originals in one step. If the copy fails halfway, photos are already gone from the handheld. Copy first, verify, then delete.
  • Unplugging mid-copy. Pulling a USB drive out while files are still writing can corrupt the file in flight. Wait for the copy to finish, or pause it first — SnapDisk's Stop button exists for exactly this.

Rule of thumb: if you have to pick the files yourself, it isn't a backup — it's a chore you will skip. Automate the copy, check it on the drive, then delete from the phone.
