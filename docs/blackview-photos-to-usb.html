Method 1: SnapDisk (one tap, background copy)

SnapDisk is a free Android app that does exactly this job and nothing else. Install it from the v0.1.2 APK (it's not on Google Play yet), then:

  1. Plug in the USB drive. It mounts on plug-in on most Blackview phones — look for a "USB storage added" notification. If nothing appears, check Settings > Storage for the drive. The BV9300, BV9300 Pro, and BV6200 Pro all have OTG, so the drive should appear on any of them.
  2. Open SnapDisk and check the folders. The app opens to a settings screen with a From folder and a To folder, each with a folder picker. The defaults are already right for most people: From /sdcard/DCIM (your camera photos — Blackview camera photos live in DCIM/Camera), To /disk/DCIM on the drive. If your photos live somewhere else, tap the From picker and choose that folder — the picker is the Android system folder picker, and the app keeps access to it.
  3. Tap Backup. SnapDisk offers a backup in a notification when the drive connects: "External storage is connected. Backup photos?" Tap it and your whole library copies oldest-first — your earliest photos first — in the background, while you use the phone normally. The copy mirrors the source folder structure on the drive, so DCIM stays DCIM.
  4. Watch the progress notification — real percent, copied / total size, speed, and time left — with Pause and Stop. You can pause and resume any time.
  5. Wait for "Backup complete." Every file is size-verified after copying, so the counts are proof, not a promise. Files that already copied are never copied twice — so if the free 5 GB per-run limit stops a big library partway, just run it again and it picks up where it left off.

The copies are the original files. SnapDisk streams each file byte-for-byte from the phone to the drive — the code reads the file and writes the same bytes out, with no decode, no recompression, and no resize — and then checks that the copy on the drive is the same size as the original. Other apps copy originals byte-for-byte too; what SnapDisk adds is the automated whole-library run: oldest-first order, progress with Pause and Stop, resume where it stopped, and skip-if-already-copied on the next run. If a file is corrupt or too big for FAT32, it's retried once, then skipped with its reason listed — it never stalls the whole backup. The free version backs up manually, up to 5 GB per backup run, with no ads, no account, and no cloud. SnapDisk Pro is a one-time $9.99 purchase (no subscription) that starts the backup automatically when you plug in a disk and removes the size limit. The app has no internet permission, so your photos physically cannot leave your device.

Method 2: a file manager (the stock route, no app needed)

A file manager can copy your photos to the USB drive — Blackview's own backup guide says to manually copy your files to microSD or USB OTG storage, and Files by Google can access USB storage on Android 7.0 and later, and either is the manual route Blackview documents for external storage: 1. Plug in the USB drive — a notification should appear saying "USB storage added"; tap it to open the drive. If nothing appears, check Settings > Storage for the drive. 2. Open the file manager and confirm the USB drive shows up under storage devices. 3. Go back to Internal storage, DCIM, Camera, where your camera photos live. 4. Select the photos (long-press the first, tap the rest, or select all). 5. Tap Copy, then select the USB drive, and wait for the copy to finish — don't unplug the drive until the file manager says it's done. Eject the drive from the notification or from Settings > Storage before unplugging it. Use Copy, not Move: Move deletes the originals as it goes, so a bumped cable halfway through loses photos. This works fine for a one-off copy. Its limits are the reason SnapDisk exists: you pick files one by one, there is no progress detail beyond a spinner, no resume if you unplug mid-copy, no verification that every file actually arrived, and you have to repeat the whole manual selection next time photos pile up. For a library that grows every day, the app's oldest-first background copy is the calmer option.

Method 3: Blackview's own tools (the 6 ways, Google Photos, Google backup, Data Migration — not phone-to-USB)

If you want Blackview's own route, know what each tool actually does — Blackview's own backup guide is six generic Android ways, and none of them writes your photos as plain files to a USB drive automatically. 1. Google Account Backup is Blackview's own first way — Settings > Google > Backup, "Back up to Google One" on — it backs apps, settings, photos, videos, and contacts up to your Google account. It is a real backup — but it is a cloud backup, not a USB copy, and Google accounts only offer 15 GB of free storage, which Blackview's own guide says may not be sufficient for photos and videos. 2. Local Backup to Computer is Blackview's own second way — connect the phone to a computer with a USB cable, open File Explorer or Finder, and copy the files to the computer's local storage or an external hard drive. It is a real backup — but it needs a PC in between, and the backup lands on the PC, not on a USB drive as plain files straight from the phone. 3. Third-party backup apps is Blackview's own third way — Google One, Dropbox, MEGA, Box, Samsung Smart Switch, OneDrive, and Titanium Backup (which needs root). They are real backups — but they are cloud apps or a PC tool, not a phone-to-USB copy, and Blackview's own guide tells you to review each app's privacy policy before trusting it with your data. 4. Backup to External Storage is Blackview's own fourth way — "many Android phones support the use of a microSD card or USB OTG storage — you can use these external storage options to manually copy your important files, photos, and other data for a local backup." It is the closest thing in Blackview's own guide to this article's job — but it is a manual copy, and the manual copy is Method 2 above. 5. ADB backup is Blackview's own fifth way — enable Developer Options and USB Debugging, install Android Platform Tools on a computer, connect the phone, and run the ADB backup command. It is a real backup — but it needs a computer and command-line tools, and some apps block ADB backups. 6. Custom recovery is Blackview's own sixth way — unlock the bootloader, install TWRP, and create a full system image. It is a real backup — but it is expert level, and Blackview's own guide says it may void warranties or risk data loss if done incorrectly. Data Migration is Blackview's phone-to-phone tool — a few taps transfer all your data from an old device to a new one. It is a real transfer — but it moves data to a new phone, not to a USB drive. Google Photos is Google's own photo backup app, and it is the stock photo backup on Blackview phones: open Photos, tap your profile picture, Photos settings, Backup, and turn Backup on — it automatically backs up photos to your Google account, with 15 GB free with every Google account. It is a real backup — but it is a cloud backup, not a USB copy, and photos sync through Google Photos instead. Google backup is the other Google route: Settings > System > Backup, Back up to Google Drive on — it backs the phone up to your Google account so you can restore app settings and data to a new phone. It is a real backup — but the backup lives in Google's cloud and restores to a phone, not a folder of photo files on a USB drive you can plug into any computer and open. All of them work fine for what they are. Their limit, for photos specifically: none of them gives you a folder of plain photo files on a USB drive you can plug into any computer and open. If what you want is a copy of your photos you can open anywhere, Method 1 or 2 is the route — that is the gap this article fills, as of November 17, 2026.

What this does not do

A few honest limits, so the automatic copy is not oversold:

  • Photos and videos only. SnapDisk copies image and video files. Documents, voice notes, and anything that isn't a photo or video is skipped — Google backup is the tool if you want contacts, messages, and settings in the same backup, not just photos.
  • Only the folder you pick. By default that's DCIM — your camera photos. Photos in other folders (Downloads, app folders) only copy if you point the From folder at them, or at a parent folder that contains them.
  • Free 5 GB per run. A library bigger than 5 GB stops at the cap; run it again and it picks up where it stopped. Pro ($9.99, one-time) removes the limit and starts the backup automatically when you plug in a disk.
  • Files over 4 GB on FAT32 are skipped. Very long videos on a FAT32 drive are listed with their reason instead of failing the backup. Reformat the drive to exFAT if you need them.
  • It never deletes. SnapDisk only copies. Freeing space on the phone is copy, check the copy on the drive, then delete the originals yourself — never the other way round.
  • The microSD slot shares the SIM tray on some models. The BV9300's microSDXC slot uses the shared SIM slot, so a card and a second SIM compete for the same tray. SnapDisk still needs Android 7.0 or later.

What to avoid

  • Buying an adapter you don't need. A USB-C flash drive plugs straight into any current Blackview — the BV9300, BV9300 Pro, and BV6200 Pro all have USB-C with OTG — so an adapter is only needed for a regular USB-A drive.
  • Mistaking a cloud backup for a photo copy. Google backup and Google Photos back your phone up to Google's servers — if you want to plug the drive into a computer and open the pictures, you need a plain copy, that is Method 1 or 2, not a cloud backup.
  • Mistaking a PC tool for a phone-to-USB copy. Blackview's own second way backs your phone up — but it is a local backup to a computer, and the backup lands on the PC. If the phone and the drive are all you have, a phone-to-USB copy is the route, not a desktop tool.
  • Mistaking a PC backup for a USB backup. Blackview's own second way backs your phone up to a computer — a real backup, but it lands on the PC, not on a USB drive you can plug into any computer and open.
  • Mistaking a phone-to-phone transfer for a USB backup. Blackview's Data Migration transfers all your data from an old device to a new one — a real transfer, but it moves data to a new phone, not to a USB drive you can plug into any computer and open.
  • Mistaking a manual copy for an automated backup. Blackview's own fourth way — manually copy your files to microSD or USB OTG storage — is a real local copy, but it is manual select-copy-paste with no progress detail, no resume, and no verification. If you want the whole library copied oldest-first in the background, that is Method 1, not a manual copy.
  • Mistaking an expert tool for a photo backup. ADB backup needs a computer and command-line tools, and custom recovery needs an unlocked bootloader and may void the warranty — Blackview's own guide marks both as advanced or expert level. Neither is a one-tap way to copy your camera roll to a drive.
  • Mistaking a microSD copy for a USB backup. Copying DCIM to a memory card is a real local copy — the BV9300 and the BV6200 Pro both have a microSDXC slot up to 1 TB — but the card stays in the phone, and opening it anywhere else needs a card reader; a USB drive plugs into any computer as it is. On the BV9300 the card uses the shared SIM slot.
  • PC-only tools when you have no computer. Drag-and-drop through a Windows PC works — but it needs the PC in between. If the phone and the drive are all you have, a phone-to-USB copy is the route — that is the gap this article fills, as of November 17, 2026.
  • Cloud backup dressed as USB backup. If the app needs an account and an upload before your photos are safe, that's a cloud subscription with a USB step. Your photos sit on someone else's server, and the backup stops working the day you stop paying. On Blackview the cloud routes are Google Photos and Google backup — and Google Photos' "Storage saver" setting compresses photos, which is the one place quality actually gets lost.
  • Deleting before verifying. A backup is only a backup once you've confirmed the copy. Copy, open a few photos on the drive, then delete from the phone — never the other way round. SnapDisk only copies — it never deletes — so the delete step is always yours, and always after the check.
  • Moving instead of copying. The file manager's Move option copies and then deletes the originals in one step. If the copy fails halfway, photos are already gone from the phone. Copy first, verify, then delete.
  • Unplugging mid-copy. Pulling a USB drive out while files are still writing can corrupt the file in flight. Wait for the copy to finish, or pause it first — SnapDisk's Stop button exists for exactly this.

Rule of thumb: if you have to pick the files yourself, it isn't a backup — it's a chore you will skip. Automate the copy, check it on the drive, then delete from the phone.
