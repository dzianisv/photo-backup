Method 1: SnapDisk (one tap, background copy)

SnapDisk is a free Android app that does exactly this job and nothing else. Install it from the v0.1.2 APK (it's not on Google Play yet), then:

  1. Check your model can run SnapDisk — and host a drive. Every covered Bartec model runs Android 9 or later, so SnapDisk installs on all five. The drive is the harder half: on the SP9EX1 models, plug in a drive and look for the mount notification — no source found labels the USB-C port OTG, so the mounting is the test. On the PIXAVI models, try a drive through Bartec's own USB Safe Box cable and look for the mount notification — no source found says the magnetic connector hosts a drive, so if nothing mounts, the phone may not support USB storage at all and the computer copy in Method 4 is the route.
  2. Use only Bartec approved chargers and cables. Bartec's user guide says so — for connection to computers and car chargers, use only the Bartec approved USB Safe Box cable G7-S0Z0-0006. Use that cable on the PIXAVI line, and a standard USB-C OTG adapter on the SP9EX1 line. The guide also says the USB port may be used for charging only in a non-hazardous area — so do the backup outside the hazardous area, and follow your site's own rules before connecting anything inside one.
  3. Plug in the USB drive. On the SP9EX1 models use a USB-C OTG adapter for a USB-A drive. A USB-C dual drive plugs straight into the SP9EX1 models with no adapter. On the PIXAVI models there is no standard port — the only connection is the magnetic USB connector, so the drive goes through Bartec's own USB Safe Box cable and a standard OTG adapter does not fit. It mounts on plug-in on most Android devices with USB host support — look for a "USB storage added" notification. If nothing appears, check Settings > Storage for the drive. Start with a charged battery, or a charged spare in your pocket on the PIXAVI models with replaceable batteries: the drive occupies the phone's only USB connection while it copies.
  4. Open SnapDisk and check the folders. The app opens to a settings screen with a From folder and a To folder, each with a folder picker. The defaults are already right for most people: From /sdcard/DCIM (your camera photos — Bartec camera photos live in DCIM/Camera), To /disk/DCIM on the drive. If your photos live somewhere else, tap the From picker and choose that folder — the picker is the Android system folder picker, and the app keeps access to it.
  5. Tap Backup. SnapDisk offers a backup in a notification when the drive connects: "External storage is connected. Backup photos?" Tap it and your whole library copies oldest-first — your earliest photos first — in the background, while you use the device normally. The copy mirrors the source folder structure on the drive, so DCIM stays DCIM.
  6. Watch the progress notification — real percent, copied / total size, speed, and time left — with Pause and Stop. You can pause and resume any time.
  7. Wait for "Backup complete." Every file is size-verified after copying, so the counts are proof, not a promise. Files that already copied are never copied twice — so if the free 5 GB per-run limit stops a big library partway, just run it again and it picks up where it left off.

The copies are the original files. SnapDisk streams each file byte-for-byte from the device to the drive — the code reads the file and writes the same bytes out, with no decode, no recompression, and no resize — and then checks that the copy on the drive is the same size as the original. Other apps copy originals byte-for-byte too; what SnapDisk adds is the automated whole-library run: oldest-first order, progress with Pause and Stop, resume where it stopped, and skip-if-already-copied on the next run. If a file is corrupt or too big for FAT32, it's retried once, then skipped with its reason listed — it never stalls the whole backup. The free version backs up manually, up to 5 GB per backup run, with no ads, no account, and no cloud. SnapDisk Pro is a one-time $9.99 purchase (no subscription) that starts the backup automatically when you plug in a disk and removes the size limit. The app has no internet permission, so your photos physically cannot leave your device.

Method 2: the built-in file manager (the stock route, no app needed)

The built-in file manager can copy your photos to the USB drive — on near-stock Android that is Files by Google, and no source found names the stock file manager on a Bartec device, so the stock route is the Android one: 1. Use only Bartec approved chargers and cables — Bartec's user guide says so — and do the backup outside the hazardous area, since the guide says the USB port may be used for charging only in a non-hazardous area. 2. Plug in the USB drive — on the SP9EX1 models with a USB-C OTG adapter, on the PIXAVI models through Bartec's own USB Safe Box cable, if the drive mounts at all. A notification should appear saying "USB storage added"; tap it to open the drive. If nothing appears, check Settings > Storage for the drive. 3. Open the file manager and confirm the USB drive shows up under storage devices. 4. Go back to Internal storage, DCIM, Camera, where your camera photos live. 5. Select the photos (long-press the first, tap the rest, or select all). 6. Tap Copy, then select the USB drive, and wait for the copy to finish — don't unplug the drive until the file manager says it's done. Eject the drive from the notification or from Settings > Storage before unplugging it. Use Copy, not Move: Move deletes the originals as it goes, so a bumped cable halfway through loses photos. This works fine for a one-off copy. Its limits are the reason SnapDisk exists: you pick files one by one, there is no progress detail beyond a spinner, no resume if you unplug mid-copy, no verification that every file actually arrived, and you have to repeat the whole manual selection next time photos pile up. For a library that grows every day, the app's oldest-first background copy is the calmer option.

Method 3: Google Photos, Google Drive, or a microSD card — not phone-to-USB plain files

With Google Drive you have 15Gb free" — it backs your data up to Google's cloud. It is a real backup — but it backs up settings, not a folder of photo files on a drive you hold. 4. A microSD card is the local option on the PIXAVI line only — the Phone and Thermal take 1x microSD alongside a nano-SIM, the Cam takes 1x microSD. It is a real local copy — but the card stays in the device, and opening the card anywhere else needs a card reader, and no source found states microSD support for the SP9EX1 at all, so on an SP9EX1 there may be no card route in the first place. 5. SIPIDO is the app Bartec's older phones shipped with — a telepresence app for live video calls and remote support, not a backup tool. It streams video; it does not copy your camera roll to a drive. None of them is a one-tap way to copy your camera roll to a drive as plain files. All of them work fine for what they are. Their limit, for photos specifically: none of them gives you a folder of plain photo files on a USB drive you can plug into any computer and open. Method 4: through a computer (if you have one)

If a PC or Mac is handy, the old route still works: plug the phone into the computer with a USB cable, tap the USB notification and choose File transfer — and drag the DCIM folder onto the USB drive. On the PIXAVI line the cable is Bartec's own USB Safe Box cable; on the SP9EX1 line it is a USB-C cable. This works fine, and it is the only route above that needs a second device in between. It is also the fallback for the PIXAVI line if the magnetic connector never hosts a drive: the computer reads the phone as storage, and the drive plugs into the computer. If the phone and the drive are all you have, Method 1 or 2 is the route — that is the gap this article fills, as of November 19, 2026.

What this does not do

A few honest limits, so the automatic copy is not oversold:

  • Photos and videos only. SnapDisk copies image and video files. Documents, voice notes, and anything that isn't a photo or video is skipped — Google backup is the tool if you want contacts, messages, and settings in the same backup, not just photos.
  • Only the folder you pick. By default that's DCIM — your camera photos. Photos in other folders (Downloads, app folders) only copy if you point the From folder at them, or at a parent folder that contains them.
  • Free 5 GB per run. A library bigger than 5 GB stops at the cap; run it again and it picks up where it stopped. Pro ($9.99, one-time) removes the limit and starts the backup automatically when you plug in a disk.
  • Files over 4 GB on FAT32 are skipped. Very long videos on a FAT32 drive are listed with their reason instead of failing the backup. Reformat the drive to exFAT if you need them.
  • It never deletes. SnapDisk only copies. Freeing space on the device is copy, check the copy on the drive, then delete the originals yourself — never the other way round.
  • The connector differs by line, not by model. The PIXAVI line has only a magnetic USB connector — no standard OTG adapter fits it — while the SP9EX1 line has USB-C, so a USB-A drive needs a USB-C OTG adapter. A plain USB-C charging cable is not a host connection: it connects the phone to a computer, which is the opposite direction.
  • OTG is confirmed on none of the five — and on the PIXAVI line the drive may not attach at all. No source found labels any Bartec USB port OTG. On the SP9EX1 models the datasheets list only a "USB-C Port" under External I/O, so plug in a drive and look for the mount notification — or run a USB OTG Checker app — before buying an adapter. On the PIXAVI models there is no standard port at all, only the magnetic connector, and no source found says that connector hosts a USB drive — so try a drive through Bartec's own USB Safe Box cable first, and if nothing mounts, use the computer copy in Method 4.
  • Use only Bartec approved chargers and cables. Bartec's user guide says so, and the USB port may be used for charging only in a non-hazardous area — do the backup outside the hazardous area. What to avoid

  • Buying a standard OTG adapter for a PIXAVI. The PIXAVI line has no standard USB port — only a magnetic USB connector — so a USB-C or micro-USB OTG adapter has nothing to plug into. The drive goes through Bartec's own USB Safe Box cable, if it mounts at all.
  • Assuming OTG because the phone has USB-C. The SP9EX1 models both have a USB-C port, and no source found labels either port OTG — the datasheets list only a "USB-C Port" under External I/O. Plug in a drive and look for the mount notification before buying an adapter — USB-C is a connector shape, not a promise the phone hosts drives.
  • Assuming the PIXAVI's magnetic connector hosts a drive. The magnetic connector is for charging and data transfer through Bartec's cable — no source found says it acts as a USB host. Try a drive through Bartec's own USB Safe Box cable and look for the mount notification before planning a backup around it; if nothing mounts, the computer copy in Method 4 is the route.
  • Assuming your PIXAVI Phone is on Android 11 because the line goes that high. The PIXAVI Phone shipped on Android 9 in its 2022 datasheet and lists Android 11 in its 2023 datasheet — check Settings > About phone on your unit instead of trusting a version printed for another model.
  • Assuming your SP9EX1 takes a microSD card. No source found states microSD support for the SP9EX1 — on an SP9EX1 the USB drive may be the only local copy that leaves the device; on a PIXAVI the card stays in the device and still needs a card reader anywhere else.
  • Assuming your SP9EX1 charges while the drive is connected. The drive occupies the phone's only USB-C port while it copies, so charge it fully before a long backup instead of counting on charging mid-backup. The PIXAVI models have replaceable batteries — carry a charged spare.
  • Using a random cable instead of a Bartec approved one. Bartec's user guide says to use only Bartec approved chargers and cables, and the USB port may be used for charging only in a non-hazardous area. A generic cable is not a Bartec approved accessory on paper — test the drive mounting with it outside the hazardous area, and do not rely on it inside one.
  • Mistaking a cloud backup for a photo copy. Google Drive and Google Photos back your phone up to Google's servers — if you want to plug the drive into a computer and open the pictures, you need a plain copy, that is Method 1 or 2, not a cloud backup. And Google Photos' "Storage saver" setting compresses photos, which is the one place quality actually gets lost.
  • Mistaking SIPIDO for a photo backup. SIPIDO is the telepresence app Bartec's older phones shipped with — it streams live video for remote support, it does not copy your camera roll to a drive. If the drive and the phone are all you have and you want files you can open anywhere, a phone-to-USB copy is the route, not a video-call app.
  • Mistaking a spec sheet or a manual for a phone-to-USB guide. The datasheets and the user guide are real documents — but they only list an Android version, a processor, a camera, or a USB connector type. None of them describes copying your camera roll straight to a USB drive from the phone. The generic Android guides in the search results are the closest thing to a phone-to-USB guide, and none of them mentions Bartec.
  • Mistaking a drive-locked app for a general backup. Photo Backup Stick DC is a real one-tap backup app — but it only works with genuine Photo Backup Stick OTG drives. If the drive you already own is any other brand, that app cannot use it: SnapDisk, Photos to USB, and FotoSafe work with any drive.
  • Mistaking a microSD card copy for a USB backup. Copying DCIM to a microSD card is a real local copy — on the PIXAVI line, which takes microSD — but the card stays in the device, and opening it anywhere else needs a card reader; a USB drive plugs into any computer as it is. And on the SP9EX1 line no source found states microSD support at all.
  • PC-only tools when you have no computer. Drag-and-drop through a Windows PC works — but it needs the PC in between. If the phone and the drive are all you have, a phone-to-USB copy is the route — that is the gap this article fills, as of November 19, 2026.
  • Cloud backup dressed as USB backup. If the app needs an account and an upload before your photos are safe, that's a cloud subscription with a USB step. Your photos sit on someone else's server, and the backup stops working the day you stop paying. On a Bartec phone the cloud routes are Google Photos and Google Drive — and Google Photos' "Storage saver" setting compresses photos, which is the one place quality actually gets lost.
  • Deleting before verifying. A backup is only a backup once you've confirmed the copy. Copy, open a few photos on the drive, then delete from the phone — never the other way round. SnapDisk only copies — it never deletes — so the delete step is always yours, and always after the check.
  • Moving instead of copying. A file manager's Move option copies and then deletes the originals in one step. If the copy fails halfway, photos are already gone from the phone. Copy first, verify, then delete.
  • Unplugging mid-copy. Pulling a USB drive out while files are still writing can corrupt the file in flight. Wait for the copy to finish, or pause it first — SnapDisk's Stop button exists for exactly this.

Rule of thumb: if you have to pick the files yourself, it isn't a backup — it's a chore you will skip. Automate the copy, check it on the drive, then delete from the phone.
