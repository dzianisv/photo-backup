Method 1: SnapDisk (one tap, background copy)

SnapDisk is a free Android app that does exactly this job and nothing else. Install it from the v0.1.2 APK (it's not on Google Play yet), then:

  1. Check your model can run SnapDisk. The GS5 runs Android 11, the GS4 and the GS3 run Android 10, the GS290 runs Android 10, the GS190 runs Android 9, the GS185 and the GS180 run Android 8.1, the GS110 runs Android 9.0 Go Edition, the GX6 and the GX6 Pro run Android 12, the GX4 runs Android 12, the GX4 Pro runs Android 13, and the GX290 runs Android 10 — all clear the Android 7.0 minimum, so SnapDisk installs on all of them. The exception is the GS160, which runs Android 6.0 and cannot run SnapDisk at all, so Method 4 is the route on that phone. The GX30 and the GX50 list OTG on Gigaset's own site, but no source found states their Android versions, so check Settings > About phone on those two before installing. Check Settings > About phone if you are unsure which Android version your unit runs.
  2. Plug in the USB drive. A USB-C flash drive plugs straight into the USB Type-C port, and a regular USB-A drive needs a USB-C OTG adapter there. On the GS4, the GS3, the GS190, the GS185, the GS180, the GS110, the GX6 and the GX290 no source found confirms OTG at all — and on the GS3, the GS190, the GS185 and the GS180 no source found even states the connector type — so check the port on your unit and buy the adapter that fits it. It mounts on plug-in on most Android devices with USB host support — look for a "USB storage added" notification. If nothing appears, check Settings > Storage for the drive. One Gigaset wrinkle: no source found confirms OTG or host support on those eight models at all, so on them the drive mounting is the test — if the drive never appears in Settings > Storage, the device does not host drives and Method 4 is the route.
  3. Open SnapDisk and check the folders. The app opens to a settings screen with a From folder and a To folder, each with a folder picker. The defaults are already right for most people: From /sdcard/DCIM (your camera photos — Gigaset camera photos live in DCIM/Camera), To /disk/DCIM on the drive. If your photos live somewhere else, tap the From picker and choose that folder — the picker is the Android system folder picker, and the app keeps access to it.
  4. Tap Backup. SnapDisk offers a backup in a notification when the drive connects: "External storage is connected. Backup photos?" Tap it and your whole library copies oldest-first — your earliest photos first — in the background, while you use the phone normally. The copy mirrors the source folder structure on the drive, so DCIM stays DCIM.
  5. Watch the progress notification — real percent, copied / total size, speed, and time left — with Pause and Stop. You can pause and resume any time.
  6. Wait for "Backup complete." Every file is size-verified after copying, so the counts are proof, not a promise. Files that already copied are never copied twice — so if the free 5 GB per-run limit stops a big library partway, just run it again and it picks up where it left off.

The copies are the original files. SnapDisk streams each file byte-for-byte from the phone to the drive — the code reads the file and writes the same bytes out, with no decode, no recompression, and no resize — and then checks that the copy on the drive is the same size as the original. Other apps copy originals byte-for-byte too; what SnapDisk adds is the automated whole-library run: oldest-first order, progress with Pause and Stop, resume where it stopped, and skip-if-already-copied on the next run. If a file is corrupt or too big for FAT32, it's retried once, then skipped with its reason listed — it never stalls the whole backup. The free version backs up manually, up to 5 GB per backup run, with no ads, no account, and no cloud. SnapDisk Pro is a one-time $9.99 purchase (no subscription) that starts the backup automatically when you plug in a disk and removes the size limit. The app has no internet permission, so your photos physically cannot leave your phone.

Method 2: a file manager (the stock route, no app needed)

A file manager can copy your photos to the USB drive — the generic guides' route is an OTG connection with the built-in file manager, and it is the manual route for external storage: 1. Plug in the USB drive — a USB-C drive plugs straight into the USB Type-C port, a regular USB-A drive needs a USB-C OTG adapter there, and on the GS3, the GS190, the GS185 and the GS180 no source found states the connector type, so check the port on your unit. A notification should appear saying "USB storage added"; tap it to open the drive. If nothing appears, check Settings > Storage for the drive. On the eight models where no source confirms OTG, if the drive never appears, the device does not host drives and Method 4 is the route. 2. Open the file manager (Files by Google on the Android models) and confirm the USB drive shows up under storage devices. 3. Go back to Internal storage, DCIM, Camera, where your camera photos live. 4. Select the photos (long-press the first, tap the rest, or select all). 5. Tap Copy, then select the USB drive, and wait for the copy to finish — don't unplug the drive until the file manager says it's done. Eject the drive from the notification or from Settings > Storage before unplugging it. Use Copy, not Move: Move deletes the originals as it goes, so a bumped cable halfway through loses photos. This works fine for a one-off copy. Its limits are the reason SnapDisk exists: you pick files one by one, there is no progress detail beyond a spinner, no resume if you unplug mid-copy, no verification that every file actually arrived, and you have to repeat the whole manual selection next time photos pile up. For a library that grows every day, the app's oldest-first background copy is the calmer option. One note: the file-manager route works on the GS160 too — it needs no app install, so the Android 7.0 minimum does not apply to it — but that phone still needs to host the drive, so the drive mounting is the test there as well.

What this does not do

A few honest limits, so the automatic copy is not oversold:

  • Photos and videos only. SnapDisk copies image and video files. Documents, voice notes, and anything that isn't a photo or video is skipped — Google backup is the tool if you want contacts, messages, and settings in the same backup, not just photos.
  • Only the folder you pick. By default that's DCIM — your camera photos. Photos in other folders (Downloads, app folders) only copy if you point the From folder at them, or at a parent folder that contains them.
  • Free 5 GB per run. A library bigger than 5 GB stops at the cap; run it again and it picks up where it stopped. Pro ($9.99, one-time) removes the limit and starts the backup automatically when you plug in a disk.
  • Files over 4 GB on FAT32 are skipped. Very long videos on a FAT32 drive are listed with their reason instead of failing the backup. Reformat the drive to exFAT if you need them.
  • It never deletes. SnapDisk only copies. Freeing space on the phone is copy, check the copy on the drive, then delete the originals yourself — never the other way round.
  • OTG is confirmed on only seven of the fifteen Android models that can run SnapDisk. What to avoid

  • Buying an adapter you don't need — or the wrong one. A USB-C flash drive plugs straight into the GS5, the GS290, the GX6 Pro, the GX4, the GX4 Pro, the GX30 and the GX50 — so no adapter is needed on them for a USB-C drive — while a regular USB-A drive needs a USB-C OTG adapter there. On the GS3, the GS190, the GS185 and the GS180 no source found states the connector type, so check the port on your unit first. A plain USB-C charging cable is not an OTG adapter: it connects the phone to a computer, which is the opposite direction.
  • Assuming a model hosts drives because another Gigaset model does. Seven models list OTG in their spec listings — but no source found confirms it on the other eight, so test with a drive on your model, and use Method 2 or 4 on it if the drive never mounts.
  • Installing SnapDisk on a Gigaset phone below Android 7.0. The GS160 runs Android 6.0 — check Settings > About phone first: on that phone the computer copy in Method 4 is the route, not this article's one-tap method. The GX30 and the GX50 have no Android version stated in any source found, so check them too before installing.
  • Mistaking a cloud backup for a photo copy. Google Drive and Google Photos back your phone up to Google's servers — if you want to plug the drive into a computer and open the pictures, you need a plain copy, that is Method 1 or 2, not a cloud backup.
  • Mistaking a PC tool for a phone-to-USB copy. A computer copy with a USB cable moves files to a computer — but it is a copy to a computer, and the backup lands on the PC. If the phone and the drive are all you have, a phone-to-USB copy is the route, not a desktop copy.
  • Mistaking a spec table or a product page for a phone-to-USB guide. The Gigaset spec listings and product pages are real Gigaset pages — but the spec listings only list an Android version, a chipset, or a USB connector type, and the product pages only describe the hardware. Neither of them describes copying your camera roll straight to a USB drive from the phone.
  • Mistaking a manual for a phone-to-USB guide. The GX290 manual is a real Gigaset document — but it does not describe copying your camera roll straight to a USB drive from the phone.
  • Mistaking OTG support on one model for OTG support on the other. Seven models list OTG in their spec listings — but no source found confirms it on the other eight, so test with a drive on your model, and use Method 2 or 4 on it if the drive never mounts.
  • Mistaking a drive-locked app for a general backup. Photo Backup Stick DC is a real one-tap backup app — but it only works with genuine Photo Backup Stick OTG drives. If the drive you already own is any other brand, that app cannot use it: SnapDisk, Photos to USB, and FotoSafe work with any drive.
  • Mistaking a microSD card copy for a USB backup. Copying DCIM to a microSD card is a real local copy — the GS5 takes a card up to 512 GB and the GX6 Pro up to 1 TB — but the card stays in the phone, and opening it anywhere else needs a card reader; a USB drive plugs into any computer as it is.
  • PC-only tools when you have no computer. Drag-and-drop through a Windows PC works — but it needs the PC in between. If the phone and the drive are all you have, a phone-to-USB copy is the route — that is the gap this article fills, as of November 18, 2026.
  • Cloud backup dressed as USB backup. If the app needs an account and an upload before your photos are safe, that's a cloud subscription with a USB step. Your photos sit on someone else's server, and the backup stops working the day you stop paying. On a Gigaset phone the cloud routes are Google Photos and Google Drive — and Google Photos' "Storage saver" setting compresses photos, which is the one place quality actually gets lost.
  • Deleting before verifying. A backup is only a backup once you've confirmed the copy. Copy, open a few photos on the drive, then delete from the phone — never the other way round. SnapDisk only copies — it never deletes — so the delete step is always yours, and always after the check.
  • Moving instead of copying. The file manager's Move option copies and then deletes the originals in one step. If the copy fails halfway, photos are already gone from the phone. Copy first, verify, then delete.
  • Unplugging mid-copy. Pulling a USB drive out while files are still writing can corrupt the file in flight. Wait for the copy to finish, or pause it first — SnapDisk's Stop button exists for exactly this.

Rule of thumb: if you have to pick the files yourself, it isn't a backup — it's a chore you will skip. Automate the copy, check it on the drive, then delete from the phone.
