What you need

An Honor phone (Android 7.0 or later for SnapDisk); a USB drive your phone can read — a USB-C flash drive plugs straight into a modern Honor phone, or a regular USB drive with a USB-C OTG adapter; older Honor phones with a Micro-USB port need a Micro-USB OTG adapter instead; and enough space on the drive for the photos you want to keep. Three Honor specifics: first, there is no OTG switch to hunt for. On most Honor phones the drive mounts on plug-in — look for a "USB storage added" or "USB drive connected" notification. If the phone ignores the drive, search Settings for "OTG": no documented MagicOS switch location was found, and whether a switch exists at all, or switches itself off, is unverified — so don't assume a missing switch means a broken phone. Not every Honor phone has OTG at all, so if there is no OTG setting anywhere, the phone may not support it. Second, Honor's stock file manager is Files, a category-based browser (Images, Videos, Documents, Audio) that integrates with Honor Cloud, and Honor camera photos live in DCIM/Camera — and whether your model has a microSD slot varies by model, so check your own model's specs rather than assuming one either way; a USB drive is the plug-in storage that works on every model. Third, Honor phones ship with Google Play, so SnapDisk installs from the v0.1.2 APK on the GitHub release page today and from Play once the listing is live — there is no Huawei-style sideload-only situation here. One format note: drives formatted FAT32 can't hold a single file over 4 GB. That only matters for very long videos — SnapDisk skips those files and lists them instead of failing the whole backup. A drive formatted exFAT has no such limit.

Method 1: SnapDisk (one tap, background copy)

SnapDisk is a free Android app that does exactly this job and nothing else. Install it from the v0.1.2 APK (it's not on Google Play yet), then:

  1. Plug in the USB drive. Most Honor phones mount it straight away — look for a "USB storage added" notification. If nothing appears, search Settings for "OTG"; no documented MagicOS switch location was found, so there may be nothing to turn on.
  2. Open SnapDisk and check the folders. The app opens to a settings screen with a From folder and a To folder, each with a folder picker. The defaults are already right for most people: From /sdcard/DCIM (your camera photos — Honor camera photos live in DCIM/Camera), To /disk/DCIM on the drive. If your photos live somewhere else, tap the From picker and choose that folder — the picker is the Android system folder picker, and the app keeps access to it.
  3. Tap Backup. SnapDisk offers a backup in a notification when the drive connects: "External storage is connected. Backup photos?" Tap it and your whole library copies oldest-first — your earliest photos first — in the background, while you use the phone normally. The copy mirrors the source folder structure on the drive, so DCIM stays DCIM.
  4. Watch the progress notification — real percent, copied / total size, speed, and time left — with Pause and Stop. You can pause and resume any time.
  5. Wait for "Backup complete." Every file is size-verified after copying, so the counts are proof, not a promise. Files that already copied are never copied twice — so if the free 5 GB per-run limit stops a big library partway, just run it again and it picks up where it left off.

The copies are the original files. SnapDisk streams each file byte-for-byte from the phone to the drive — the code reads the file and writes the same bytes out, with no decode, no recompression, and no resize — and then checks that the copy on the drive is the same size as the original. Other apps copy originals byte-for-byte too; what SnapDisk adds is the automated whole-library run: oldest-first order, progress with Pause and Stop, resume where it stopped, and skip-if-already-copied on the next run. If a file is corrupt or too big for FAT32, it's retried once, then skipped with its reason listed — it never stalls the whole backup. Method 2: Files (the stock route, no app needed)

Honor phones ship with Files as the stock file manager, and it can copy your photos to the USB drive: 1. Plug in the USB drive — a notification should appear saying "USB storage added"; tap it to open the drive. If nothing appears, search Settings for "OTG". 2. Open Files and confirm the USB drive shows up as a storage location. 3. Go back to Internal storage, DCIM, Camera, where your camera photos live. 4. Select the photos (long-press the first, tap the rest, or select all). 5. Tap Copy, then select the USB drive, and wait for the copy to finish — don't unplug the drive until Files says it's done. Eject the drive from the notification or from Settings > Storage before unplugging it. Use Copy, not Move: Move deletes the originals as it goes, so a bumped cable halfway through loses photos. This works fine for a one-off copy. Its limits are the reason SnapDisk exists: you pick files one by one, there is no progress detail beyond a spinner, no resume if you unplug mid-copy, no verification that every file actually arrived, and you have to repeat the whole manual selection next time photos pile up. For a library that grows every day, the app's oldest-first background copy is the calmer option.

Method 3: Honor's own tools (encrypted backup, phone-to-phone, or to the cloud — not phone-to-USB)

If you want Honor's own route, know what each tool actually does — none of them writes your photos as plain files to a USB drive. Honor's Backup & restore can write to a USB drive — Settings > System & updates > Backup & restore > Data backup > External storage > USB storage — but what it writes is an encrypted backup package, with a password you set yourself, that you can only restore through Honor's Backup on an Honor phone. It is a real USB backup, and it is the closest Honor's own tools come to this article's job — but the backup is a package, not a folder of photo files you can plug into any computer and open. Honor Share is Honor's official wireless sharing tool: it moves images, videos, and documents between Honor phones over Wi-Fi Direct, or between a phone and an Honor notebook with PC Manager 15.0 and above — but it needs a second Honor device on the other end, and it moves data to that device, not to a USB drive. Device Clone is the same idea for switching phones: it moves everything from an old phone to a new Honor phone, and again needs a second phone. Honor Cloud is Honor's official cloud service: sign in with an Honor ID and it backs the phone up to Honor's servers, automatically, with a limited free tier — but it is a cloud backup, not a USB copy, and photos sync through the Gallery app or Google Photos instead. All of them work fine for what they are. Their limit, for photos specifically: none of them gives you a folder of plain photo files on a USB drive you can plug into any computer and open. If what you want is a copy of your photos you can open anywhere, Method 1 or 2 is the route — that is the gap this article fills, as of November 16, 2026.

Method 4: through a computer (if you have one)

If a PC or Mac is handy, the old route still works: plug the Honor phone into the computer with a USB cable, tap the USB notification and choose File transfer (by default an Honor phone charges only) — and drag the DCIM folder onto the USB drive, or use HonorSuite, Honor's official PC tool, which backs the phone up to the computer in a few clicks. This works fine, and it is the only route above that needs a second device in between. If the phone and the drive are all you have, Method 1 or 2 is the route — that is the gap this article fills, as of November 16, 2026.

What this does not do

A few honest limits, so the automatic copy is not oversold:

  • Photos and videos only. SnapDisk copies image and video files. Documents, voice notes, and anything that isn't a photo or video is skipped — Honor Cloud is the tool if you want contacts, messages, and settings in the same backup, not just photos.
  • Only the folder you pick. By default that's DCIM — your camera photos. Photos in other folders (Downloads, app folders) only copy if you point the From folder at them, or at a parent folder that contains them.
  • Free 5 GB per run. A library bigger than 5 GB stops at the cap; run it again and it picks up where it stopped. Pro ($9.99, one-time) removes the limit and starts the backup automatically when you plug in a disk.
  • Files over 4 GB on FAT32 are skipped. Very long videos on a FAT32 drive are listed with their reason instead of failing the backup. Reformat the drive to exFAT if you need them.
  • It never deletes. SnapDisk only copies. Freeing space on the phone is copy, check the copy on the drive, then delete the originals yourself — never the other way round.

What to avoid

  • Hunting for an OTG switch that may not exist. No documented MagicOS switch location was found, and the Honor videos show the drive mounting on plug-in with a "USB storage added" notification. If your Honor phone ignores a drive, search Settings for "OTG" — but a missing switch is not proof the phone is broken; not every Honor phone has OTG at all.
  • Mistaking an encrypted backup for a photo copy. Honor's Backup & restore to a USB drive writes an encrypted backup package that only Honor's Backup can restore — if you want to plug the drive into a computer and open the pictures, you need a plain copy, that is Method 1 or 2, not Backup & restore.
  • Mistaking a phone-to-phone move for a photo copy. Honor Share and Device Clone move your photos to a new phone or an Honor notebook, and Honor Cloud moves them to Honor's servers — none writes your photos as files to a USB drive. If you want to plug the drive into a computer and open the pictures, you need a plain copy — that is Method 1 or 2, not Honor Share, Device Clone, or Honor Cloud.
  • PC-only tools when you have no computer. Drag-and-drop through a Windows PC, or HonorSuite, works — but both need the PC in between. If the phone and the drive are all you have, a phone-to-USB copy is the route — that is the gap this article fills, as of November 16, 2026.
  • Cloud backup dressed as USB backup. If the app needs an account and an upload before your photos are safe, that's a cloud subscription with a USB step. Your photos sit on someone else's server, and the backup stops working the day you stop paying. On Honor the cloud route is Google Photos or Honor Cloud — and Google Photos' "Storage saver" setting compresses photos, which is the one place quality actually gets lost.
  • Deleting before verifying. A backup is only a backup once you've confirmed the copy. Copy, open a few photos on the drive, then delete from the phone — never the other way round. SnapDisk only copies — it never deletes — so the delete step is always yours, and always after the check.
  • Moving instead of copying. The file manager's Move option copies and then deletes the originals in one step. If the copy fails halfway, photos are already gone from the phone. Copy first, verify, then delete.
  • Unplugging mid-copy. Pulling a USB drive out while files are still writing can corrupt the file in flight. Wait for the copy to finish, or pause it first — SnapDisk's Stop button exists for exactly this.

Rule of thumb: if you have to pick the files yourself, it isn't a backup — it's a chore you will skip. Automate the copy, check it on the drive, then delete from the phone.
