What you need

A TCL phone (Android 7.0 or later for SnapDisk) that supports OTG — check your model's specs before buying anything; a USB drive your phone can read — a USB-C flash drive plugs straight into any current TCL phone, or a regular USB drive with a USB-C OTG adapter; and enough space on the drive for the photos you want to keep. Three TCL specifics: first, OTG is not a given on every model, and TCL UI has no OTG switch to enable. TCL's own documentation describes no on/off toggle — the drive mounts on plug-in — so if a drive never appears, the model may simply not support OTG rather than needing a setting flipped. Spec tables list USB Type-C with OTG for the 50 XL NxtPaper and the 50 XE NxtPaper, and TCL's own user manual documents OTG on the TCL 30 5G. If the phone ignores the drive, check Settings > Storage. Second, TCL ships Google's apps, so the stock file manager is Files — it shows internal storage and the microSD card — and the stock photo backup is Google Photos, which "stores and backs up your photos and videos" per TCL's own manual; TCL camera photos live in DCIM/Camera — and most current TCL models have a microSDXC slot (the 50 XL, 50 XE, 40 X, and 30 V 5G all do), so check your own model's specs rather than assuming one either way; a USB drive is the plug-in storage that works on every model and plugs into any computer as it is. Third, TCL phones sold in the US and Europe ship with Google Play, so SnapDisk installs from the v0.1.2 APK on the GitHub release page today and from Play once the listing is live — there is no sideload-only situation here. One format note: drives formatted FAT32 can't hold a single file over 4 GB. That only matters for very long videos — SnapDisk skips those files and lists them instead of failing the whole backup. A drive formatted exFAT has no such limit.

Method 1: SnapDisk (one tap, background copy)

SnapDisk is a free Android app that does exactly this job and nothing else. Install it from the v0.1.2 APK (it's not on Google Play yet), then:

  1. Plug in the USB drive. Most OTG models mount it straight away — look for a "USB storage added" notification. TCL UI has no OTG switch to enable, so there is nothing to turn on first. If nothing appears, check Settings > Storage. Spec tables list USB Type-C with OTG for the 50 XL NxtPaper and the 50 XE NxtPaper, and TCL's own user manual documents OTG on the TCL 30 5G.
  2. Open SnapDisk and check the folders. The app opens to a settings screen with a From folder and a To folder, each with a folder picker. The defaults are already right for most people: From /sdcard/DCIM (your camera photos — TCL camera photos live in DCIM/Camera), To /disk/DCIM on the drive. If your photos live somewhere else, tap the From picker and choose that folder — the picker is the Android system folder picker, and the app keeps access to it.
  3. Tap Backup. SnapDisk offers a backup in a notification when the drive connects: "External storage is connected. Backup photos?" Tap it and your whole library copies oldest-first — your earliest photos first — in the background, while you use the phone normally. The copy mirrors the source folder structure on the drive, so DCIM stays DCIM.
  4. Watch the progress notification — real percent, copied / total size, speed, and time left — with Pause and Stop. You can pause and resume any time.
  5. Wait for "Backup complete." Every file is size-verified after copying, so the counts are proof, not a promise. Files that already copied are never copied twice — so if the free 5 GB per-run limit stops a big library partway, just run it again and it picks up where it left off.

The copies are the original files. SnapDisk streams each file byte-for-byte from the phone to the drive — the code reads the file and writes the same bytes out, with no decode, no recompression, and no resize — and then checks that the copy on the drive is the same size as the original. Other apps copy originals byte-for-byte too; what SnapDisk adds is the automated whole-library run: oldest-first order, progress with Pause and Stop, resume where it stopped, and skip-if-already-copied on the next run. If a file is corrupt or too big for FAT32, it's retried once, then skipped with its reason listed — it never stalls the whole backup. The free version backs up manually, up to 5 GB per backup run, with no ads, no account, and no cloud. SnapDisk Pro is a one-time $9.99 purchase (no subscription) that starts the backup automatically when you plug in a disk and removes the size limit. The app has no internet permission, so your photos physically cannot leave your device.

Method 2: Files (the stock route, no app needed)

TCL phones ship with Files as the stock file manager, and it can copy your photos to the USB drive: 1. Plug in the USB drive — a notification should appear saying "USB storage added"; tap it to open the drive. If nothing appears, check Settings > Storage. 2. Open Files and confirm the USB drive shows up under external storage. 3. Go back to Internal storage, DCIM, Camera, where your camera photos live. 4. Select the photos (long-press the first, tap the rest, or select all). 5. Tap Copy, then select the USB drive, and wait for the copy to finish — don't unplug the drive until Files says it's done. Eject the drive from the notification or from Settings > Storage before unplugging it. Use Copy, not Move: Move deletes the originals as it goes, so a bumped cable halfway through loses photos. This works fine for a one-off copy. Its limits are the reason SnapDisk exists: you pick files one by one, there is no progress detail beyond a spinner, no resume if you unplug mid-copy, no verification that every file actually arrived, and you have to repeat the whole manual selection next time photos pile up. For a library that grows every day, the app's oldest-first background copy is the calmer option.

Method 3: TCL's own tools (Google Photos and Google backup — not phone-to-USB)

If you want TCL's own route, know what each tool actually does — TCL has no backup tool of its own; the routes on a TCL phone are Google's, plus PC tools, and none of them writes your photos as plain files to a USB drive. Google Photos is Google's own photo backup app, and it is the stock photo backup on TCL — TCL's own manual says Google Photos "stores and backs up your photos and videos": open Photos, tap your profile picture, Photos settings, Backup, and turn Backup on — it automatically backs up photos to your Google account, with 15 GB free with every Google account. It is a real backup — but it is a cloud backup, not a USB copy, and photos sync through Google Photos instead. Google backup is the route the TCL guides point to first: Settings > Google > Backup, Back up by Google One on — it backs the phone up to your Google account so you can restore app settings and data to a new phone. It is a real backup — but the backup lives in Google's cloud and restores to a phone, not a folder of photo files on a USB drive you can plug into any computer and open. Coolmuster Android Assistant is a PC tool: install it on the computer, connect the phone with a USB cable, and back the phone up to the PC — but that needs a PC in between, and the backup lands on the PC, not on a USB drive. TWRP Recovery and Titanium Backup are the other routes the TCL backup guides list: TWRP is a custom recovery that writes a whole-device backup, and Titanium Backup is a backup tool that needs a rooted phone — both are real backups, but they need a custom recovery or root and a PC or a card to hold the backup, and neither gives you a folder of plain photo files on a USB drive. All of them work fine for what they are. Their limit, for photos specifically: none of them gives you a folder of plain photo files on a USB drive you can plug into any computer and open. If what you want is a copy of your photos you can open anywhere, Method 1 or 2 is the route — that is the gap this article fills, as of November 17, 2026.

If a PC or Mac is handy, the old route still works: plug the TCL phone into the computer with a USB cable, tap the USB notification and choose File transfer (by default a TCL phone charges only — TCL's own FAQ says to pick the mode under Settings > Connections > USB) — and drag the DCIM folder onto the USB drive. What this does not do

A few honest limits, so the automatic copy is not oversold:

  • Photos and videos only. SnapDisk copies image and video files. Documents, voice notes, and anything that isn't a photo or video is skipped — Google backup is the tool if you want contacts, messages, and settings in the same backup, not just photos.
  • Only the folder you pick. By default that's DCIM — your camera photos. Photos in other folders (Downloads, app folders) only copy if you point the From folder at them, or at a parent folder that contains them.
  • Free 5 GB per run. A library bigger than 5 GB stops at the cap; run it again and it picks up where it stopped. Pro ($9.99, one-time) removes the limit and starts the backup automatically when you plug in a disk.
  • Files over 4 GB on FAT32 are skipped. Very long videos on a FAT32 drive are listed with their reason instead of failing the backup. Reformat the drive to exFAT if you need them.
  • It never deletes. SnapDisk only copies. Freeing space on the phone is copy, check the copy on the drive, then delete the originals yourself — never the other way round.
  • No OTG, no USB backup. On a model without working OTG — spec tables list OTG for the 50 XL NxtPaper and the 50 XE NxtPaper, and TCL's own manual documents OTG on the 30 5G, but check your own model's specs before buying an adapter — a USB drive may simply never appear, and no app can change that. The cloud routes (Google Photos and Google backup) are the backup for those phones.

What to avoid

  • Buying an adapter before checking OTG. Not every TCL phone is confirmed to have OTG — check your own model's specs first, or the drive will never appear no matter what you plug in.
  • Looking for an OTG switch that isn't there. TCL UI has no OTG toggle in TCL's own documentation — the drive mounts on plug-in, so if nothing appears, check Settings > Storage rather than hunting for a switch. TCL's USB mode setting (Settings > Connections > USB) is for connecting to a computer, not for a drive, and its default is charge-only.
  • Mistaking a cloud backup for a photo copy. Google backup and Google Photos back your phone up to Google's servers — if you want to plug the drive into a computer and open the pictures, you need a plain copy, that is Method 1 or 2, not a cloud backup.
  • Mistaking a PC tool for a phone-to-USB copy. Drag-and-drop through a computer works — but it needs the PC in between. If the phone and the drive are all you have, a phone-to-USB copy is the route, not a desktop tool.
  • Mistaking a PC backup for a USB backup. Coolmuster Android Assistant backs your TCL phone up to a computer — a real backup, but it lands on the PC, not on a USB drive you can plug into any computer and open.
  • Mistaking a microSD copy for a USB backup. Copying DCIM to a memory card is a real local copy — but most current TCL models have the slot built in, the card stays in the phone, and opening it anywhere else needs a card reader; a USB drive plugs into any computer as it is.
  • PC-only tools when you have no computer. Drag-and-drop through a Windows PC works — but it needs the PC in between. If the phone and the drive are all you have, a phone-to-USB copy is the route — that is the gap this article fills, as of November 17, 2026.
  • Cloud backup dressed as USB backup. If the app needs an account and an upload before your photos are safe, that's a cloud subscription with a USB step. Your photos sit on someone else's server, and the backup stops working the day you stop paying. On TCL the cloud routes are Google Photos and Google backup — and Google Photos' "Storage saver" setting compresses photos, which is the one place quality actually gets lost.
  • Deleting before verifying. A backup is only a backup once you've confirmed the copy. Copy, open a few photos on the drive, then delete from the phone — never the other way round. SnapDisk only copies — it never deletes — so the delete step is always yours, and always after the check.
  • Moving instead of copying. The file manager's Move option copies and then deletes the originals in one step. If the copy fails halfway, photos are already gone from the phone. Copy first, verify, then delete.
  • Unplugging mid-copy. Pulling a USB drive out while files are still writing can corrupt the file in flight. Wait for the copy to finish, or pause it first — SnapDisk's Stop button exists for exactly this.

Rule of thumb: if you have to pick the files yourself, it isn't a backup — it's a chore you will skip. Automate the copy, check it on the drive, then delete from the phone.
