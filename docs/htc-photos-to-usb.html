Method 1: SnapDisk (one tap, background copy)

SnapDisk is a free Android app that does exactly this job and nothing else. Install it from the v0.1.2 APK (it's not on Google Play yet), then:

  1. Plug in the USB drive. It mounts on plug-in on most HTC phones — look for a "USB storage added" notification. If nothing appears, check Settings > Storage and tap the name of the drive, as HTC's own support pages describe. The U23 Pro, Desire 22 Pro, and U23 all have OTG, so the drive should appear on any of them.
  2. Open SnapDisk and check the folders. The app opens to a settings screen with a From folder and a To folder, each with a folder picker. The defaults are already right for most people: From /sdcard/DCIM (your camera photos — HTC camera photos live in DCIM/Camera), To /disk/DCIM on the drive. If your photos live somewhere else, tap the From picker and choose that folder — the picker is the Android system folder picker, and the app keeps access to it.
  3. Tap Backup. SnapDisk offers a backup in a notification when the drive connects: "External storage is connected. Backup photos?" Tap it and your whole library copies oldest-first — your earliest photos first — in the background, while you use the phone normally. The copy mirrors the source folder structure on the drive, so DCIM stays DCIM.
  4. Watch the progress notification — real percent, copied / total size, speed, and time left — with Pause and Stop. You can pause and resume any time.
  5. Wait for "Backup complete." Every file is size-verified after copying, so the counts are proof, not a promise. Files that already copied are never copied twice — so if the free 5 GB per-run limit stops a big library partway, just run it again and it picks up where it left off.

The copies are the original files. SnapDisk streams each file byte-for-byte from the phone to the drive — the code reads the file and writes the same bytes out, with no decode, no recompression, and no resize — and then checks that the copy on the drive is the same size as the original. Other apps copy originals byte-for-byte too; what SnapDisk adds is the automated whole-library run: oldest-first order, progress with Pause and Stop, resume where it stopped, and skip-if-already-copied on the next run. If a file is corrupt or too big for FAT32, it's retried once, then skipped with its reason listed — it never stalls the whole backup. The free version backs up manually, up to 5 GB per backup run, with no ads, no account, and no cloud. SnapDisk Pro is a one-time $9.99 purchase (no subscription) that starts the backup automatically when you plug in a disk and removes the size limit. The app has no internet permission, so your photos physically cannot leave your device.

Method 2: a file manager (the stock route, no app needed)

A file manager can copy your photos to the USB drive — HTC File Manager manages files on an external USB drive, and Files by Google can access USB storage on Android 7.0 and later, and either is the route HTC documents for USB storage: 1. Plug in the USB drive — a notification should appear saying "USB storage added"; tap it to open the drive. If nothing appears, check Settings > Storage and tap the name of the drive, as HTC's own support pages describe. On Android 6 or later, HTC File Manager shows a popup that walks you through granting access to the USB storage. 2. Open the file manager and confirm the USB drive shows up under storage devices. 3. Go back to Internal storage, DCIM, Camera, where your camera photos live. 4. Select the photos (long-press the first, tap the rest, or select all). 5. Tap Copy, then select the USB drive, and wait for the copy to finish — don't unplug the drive until the file manager says it's done. Eject the drive from the notification or from Settings > Storage before unplugging it. Use Copy, not Move: Move deletes the originals as it goes, so a bumped cable halfway through loses photos. This works fine for a one-off copy. Its limits are the reason SnapDisk exists: you pick files one by one, there is no progress detail beyond a spinner, no resume if you unplug mid-copy, no verification that every file actually arrived, and you have to repeat the whole manual selection next time photos pile up. For a library that grows every day, the app's oldest-first background copy is the calmer option.

Method 3: HTC's own tools (HTC Sync Manager, HTC Backup, Google Photos, Google backup — not phone-to-USB)

If you want HTC's own route, know what each tool actually does — HTC's own backup tool is a desktop app, and it is discontinued, and the other routes are Google's, and none of them writes your photos as plain files to a USB drive. HTC Sync Manager is HTC's own tool for HTC phones — but it is a Windows and Mac desktop application: connect the phone to a PC with a USB cable, and its Transfer & Backup backs up the pictures, videos, music, contacts, and more of your device to the computer and restores them later. It is a real backup — but it needs a PC in between, the backup lands on the PC, not on a USB drive as plain files, and it is discontinued: support has ended and it will never be updated, so continuing to use it risks sync errors or data loss. HTC Backup is HTC's own phone app — but it backs up to an HTC or Google account, which is a cloud backup, not a USB copy. Google Photos is Google's own photo backup app, and it is the stock photo backup on HTC phones: open Photos, tap your profile picture, Photos settings, Backup, and turn Backup on — it automatically backs up photos to your Google account, with 15 GB free with every Google account. It is a real backup — but it is a cloud backup, not a USB copy, and photos sync through Google Photos instead. Google backup is the other Google route: Settings > System > Backup, Back up to Google Drive on — it backs the phone up to your Google account so you can restore app settings and data to a new phone. It is a real backup — but the backup lives in Google's cloud and restores to a phone, not a folder of photo files on a USB drive you can plug into any computer and open. All of them work fine for what they are. Their limit, for photos specifically: none of them gives you a folder of plain photo files on a USB drive you can plug into any computer and open. If what you want is a copy of your photos you can open anywhere, Method 1 or 2 is the route — that is the gap this article fills, as of November 17, 2026.

What this does not do

A few honest limits, so the automatic copy is not oversold:

  • Photos and videos only. SnapDisk copies image and video files. Documents, voice notes, and anything that isn't a photo or video is skipped — Google backup is the tool if you want contacts, messages, and settings in the same backup, not just photos.
  • Only the folder you pick. By default that's DCIM — your camera photos. Photos in other folders (Downloads, app folders) only copy if you point the From folder at them, or at a parent folder that contains them.
  • Free 5 GB per run. A library bigger than 5 GB stops at the cap; run it again and it picks up where it stopped. Pro ($9.99, one-time) removes the limit and starts the backup automatically when you plug in a disk.
  • Files over 4 GB on FAT32 are skipped. Very long videos on a FAT32 drive are listed with their reason instead of failing the backup. Reformat the drive to exFAT if you need them.
  • It never deletes. SnapDisk only copies. Freeing space on the phone is copy, check the copy on the drive, then delete the originals yourself — never the other way round.
  • Older HTC models use micro-USB. The HTC One and other older models have a micro-USB port, so a USB-C drive or adapter will not fit — a micro-USB OTG adapter is the route there. SnapDisk still needs Android 7.0 or later.

What to avoid

  • Buying an adapter you don't need. A USB-C flash drive plugs straight into any current HTC — the U23 Pro, Desire 22 Pro, and U23 all have USB-C with OTG — so an adapter is only needed for a regular USB-A drive, or for the micro-USB HTC One.
  • Looking for an OTG switch that may not be there. On most HTC phones the drive mounts on plug-in — if nothing appears, check Settings > Storage and tap the name of the drive, as HTC's own support pages describe, rather than hunting for a switch.
  • Mistaking a cloud backup for a photo copy. Google backup and Google Photos back your phone up to Google's servers — if you want to plug the drive into a computer and open the pictures, you need a plain copy, that is Method 1 or 2, not a cloud backup.
  • Mistaking a PC tool for a phone-to-USB copy. HTC Sync Manager backs your HTC phone up — but it is a desktop app, and the backup lands on the PC. If the phone and the drive are all you have, a phone-to-USB copy is the route, not a desktop tool.
  • Mistaking a PC backup for a USB backup. HTC Sync Manager backs your HTC phone up to a computer — a real backup, but it lands on the PC, not on a USB drive you can plug into any computer and open.
  • Trusting a discontinued tool with your only copy. HTC Sync Manager has been discontinued and support has ended — it still installs, but it will never be updated, and its sync engine should be treated with caution. Do not make it your only backup.
  • Mistaking a storage-expansion guide for a backup guide. The HTC One guide about expanding storage with a USB OTG cable is about opening files stored on the drive — it is not a guide for copying your camera roll to the drive.
  • Mistaking an OTG support page for a backup guide. HTC's own U12+ and U12 life pages explain how to view files from a USB drive — they do not back anything up. Viewing is not copying.
  • Mistaking a microSD copy for a USB backup. Copying DCIM to a memory card is a real local copy — the U23 Pro and the Desire 22 Pro both have a microSDXC slot — but the card stays in the phone, and opening it anywhere else needs a card reader; a USB drive plugs into any computer as it is. The HTC One has no microSD slot at all.
  • PC-only tools when you have no computer. Drag-and-drop through a Windows PC works — but it needs the PC in between. If the phone and the drive are all you have, a phone-to-USB copy is the route — that is the gap this article fills, as of November 17, 2026.
  • Cloud backup dressed as USB backup. If the app needs an account and an upload before your photos are safe, that's a cloud subscription with a USB step. Your photos sit on someone else's server, and the backup stops working the day you stop paying. On HTC the cloud routes are Google Photos and Google backup — and Google Photos' "Storage saver" setting compresses photos, which is the one place quality actually gets lost.
  • Deleting before verifying. A backup is only a backup once you've confirmed the copy. Copy, open a few photos on the drive, then delete from the phone — never the other way round. SnapDisk only copies — it never deletes — so the delete step is always yours, and always after the check.
  • Moving instead of copying. The file manager's Move option copies and then deletes the originals in one step. If the copy fails halfway, photos are already gone from the phone. Copy first, verify, then delete.
  • Unplugging mid-copy. Pulling a USB drive out while files are still writing can corrupt the file in flight. Wait for the copy to finish, or pause it first — SnapDisk's Stop button exists for exactly this.

Rule of thumb: if you have to pick the files yourself, it isn't a backup — it's a chore you will skip. Automate the copy, check it on the drive, then delete from the phone.
