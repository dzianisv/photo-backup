Method 1: SnapDisk (one tap, background copy)

SnapDisk is a free Android app that does exactly this job and nothing else. Install it from the v0.1.2 APK (it's not on Google Play yet), then:

  1. Plug in the USB drive. It mounts on plug-in on most Lenovo phones — look for a "USB storage added" notification. If nothing appears, check Settings > Storage, or search Settings for "OTG". The K13, K13 Pro, and Legion phones all have OTG, so the drive should appear on any of them; the Legion phones have two USB-C ports, so use either one.
  2. Open SnapDisk and check the folders. The app opens to a settings screen with a From folder and a To folder, each with a folder picker. The defaults are already right for most people: From /sdcard/DCIM (your camera photos — Lenovo camera photos live in DCIM/Camera), To /disk/DCIM on the drive. If your photos live somewhere else, tap the From picker and choose that folder — the picker is the Android system folder picker, and the app keeps access to it.
  3. Tap Backup. SnapDisk offers a backup in a notification when the drive connects: "External storage is connected. Backup photos?" Tap it and your whole library copies oldest-first — your earliest photos first — in the background, while you use the phone normally. The copy mirrors the source folder structure on the drive, so DCIM stays DCIM.
  4. Watch the progress notification — real percent, copied / total size, speed, and time left — with Pause and Stop. You can pause and resume any time.
  5. Wait for "Backup complete." Every file is size-verified after copying, so the counts are proof, not a promise. Files that already copied are never copied twice — so if the free 5 GB per-run limit stops a big library partway, just run it again and it picks up where it left off.

The copies are the original files. SnapDisk streams each file byte-for-byte from the phone to the drive — the code reads the file and writes the same bytes out, with no decode, no recompression, and no resize — and then checks that the copy on the drive is the same size as the original. Other apps copy originals byte-for-byte too; what SnapDisk adds is the automated whole-library run: oldest-first order, progress with Pause and Stop, resume where it stopped, and skip-if-already-copied on the next run. If a file is corrupt or too big for FAT32, it's retried once, then skipped with its reason listed — it never stalls the whole backup. The free version backs up manually, up to 5 GB per backup run, with no ads, no account, and no cloud. SnapDisk Pro is a one-time $9.99 purchase (no subscription) that starts the backup automatically when you plug in a disk and removes the size limit. The app has no internet permission, so your photos physically cannot leave your device.

Method 2: a file manager (the stock route, no app needed)

A file manager can copy your photos to the USB drive — Files by Google can access USB storage on Android 7.0 and later, and it is the route Google documents for USB storage: 1. Plug in the USB drive — a notification should appear saying "USB storage added"; tap it to open the drive. If nothing appears, check Settings > Storage, or search Settings for "OTG". 2. Open Files and confirm the USB drive shows up under storage devices. 3. Go back to Internal storage, DCIM, Camera, where your camera photos live. 4. Select the photos (long-press the first, tap the rest, or select all). 5. Tap Copy, then select the USB drive, and wait for the copy to finish — don't unplug the drive until Files says it's done. Eject the drive from the notification or from Settings > Storage before unplugging it. Use Copy, not Move: Move deletes the originals as it goes, so a bumped cable halfway through loses photos. This works fine for a one-off copy. Its limits are the reason SnapDisk exists: you pick files one by one, there is no progress detail beyond a spinner, no resume if you unplug mid-copy, no verification that every file actually arrived, and you have to repeat the whole manual selection next time photos pile up. For a library that grows every day, the app's oldest-first background copy is the calmer option.

What this does not do

A few honest limits, so the automatic copy is not oversold:

  • Photos and videos only. SnapDisk copies image and video files. Documents, voice notes, and anything that isn't a photo or video is skipped — Google backup is the tool if you want contacts, messages, and settings in the same backup, not just photos.
  • Only the folder you pick. By default that's DCIM — your camera photos. Photos in other folders (Downloads, app folders) only copy if you point the From folder at them, or at a parent folder that contains them.
  • Free 5 GB per run. A library bigger than 5 GB stops at the cap; run it again and it picks up where it stopped. Pro ($9.99, one-time) removes the limit and starts the backup automatically when you plug in a disk.
  • Files over 4 GB on FAT32 are skipped. Very long videos on a FAT32 drive are listed with their reason instead of failing the backup. Reformat the drive to exFAT if you need them.
  • It never deletes. SnapDisk only copies. Freeing space on the phone is copy, check the copy on the drive, then delete the originals yourself — never the other way round.
  • Older Lenovo models use micro-USB. The K12 and other older models have a micro-USB port, so a USB-C drive or adapter will not fit — a micro-USB OTG adapter is the route there. SnapDisk still needs Android 7.0 or later.

What to avoid

  • Buying an adapter you don't need. A USB-C flash drive plugs straight into any USB-C Lenovo — the K13, K13 Pro, and Legion phones all have USB-C with OTG — so an adapter is only needed for a regular USB-A drive, or for the micro-USB K12.
  • Looking for an OTG switch that may not be there. On most Lenovo phones the drive mounts on plug-in — if nothing appears, check Settings > Storage, or search Settings for "OTG", since some Android phones need the toggle on first.
  • Mistaking a cloud backup for a photo copy. Google backup and Google Photos back your phone up to Google's servers — if you want to plug the drive into a computer and open the pictures, you need a plain copy, that is Method 1 or 2, not a cloud backup.
  • Mistaking a PC tool for a phone-to-USB copy. Software Fix (Rescue and Smart Assistant) backs your Lenovo phone up — but it is a Windows PC app, and the backup lands on the PC. If the phone and the drive are all you have, a phone-to-USB copy is the route, not a desktop tool.
  • Mistaking a PC backup for a USB backup. Software Fix backs your Lenovo phone up to a computer — a real backup, but it lands on the PC, not on a USB drive you can plug into any computer and open.
  • Mistaking a laptop recovery tool for a phone backup. Lenovo OneKey Recovery restores Lenovo and IdeaPad laptops to their factory settings — it formats the system and erases all current files — and it is not a phone backup at all. Do not run it looking for your photos.
  • Mistaking a tablet guide for a phone guide. Lenovo's own USB flash drive guide is written for tablets — the steps are the same shape, but it is not a guide for backing up a Lenovo phone.
  • Mistaking a store drive for a phone backup. The WD My Book and My Passport drives on lenovo.com ship with WD Backup software for Windows and Mac — PC software for a PC backup, not a phone-to-USB copy.
  • Mistaking a microSD copy for a USB backup. Copying DCIM to a memory card is a real local copy — the K13 has a microSDXC slot — but the card stays in the phone, and opening it anywhere else needs a card reader; a USB drive plugs into any computer as it is. The Legion phones have no card slot at all.
  • PC-only tools when you have no computer. Drag-and-drop through a Windows PC works — but it needs the PC in between. If the phone and the drive are all you have, a phone-to-USB copy is the route — that is the gap this article fills, as of November 17, 2026.
  • Cloud backup dressed as USB backup. If the app needs an account and an upload before your photos are safe, that's a cloud subscription with a USB step. Your photos sit on someone else's server, and the backup stops working the day you stop paying. On Lenovo the cloud routes are Google Photos and Google backup — and Google Photos' "Storage saver" setting compresses photos, which is the one place quality actually gets lost.
  • Deleting before verifying. A backup is only a backup once you've confirmed the copy. Copy, open a few photos on the drive, then delete from the phone — never the other way round. SnapDisk only copies — it never deletes — so the delete step is always yours, and always after the check.
  • Moving instead of copying. The file manager's Move option copies and then deletes the originals in one step. If the copy fails halfway, photos are already gone from the phone. Copy first, verify, then delete.
  • Unplugging mid-copy. Pulling a USB drive out while files are still writing can corrupt the file in flight. Wait for the copy to finish, or pause it first — SnapDisk's Stop button exists for exactly this.

Rule of thumb: if you have to pick the files yourself, it isn't a backup — it's a chore you will skip. Automate the copy, check it on the drive, then delete from the phone.
