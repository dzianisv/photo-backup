What you need

An iQOO phone (Android 7.0 or later for SnapDisk) that supports OTG — check your model's specs before buying anything; a USB drive your phone can read — a USB-C flash drive plugs straight into any current iQOO phone, or a regular USB drive with a USB-C OTG adapter; and enough space on the drive for the photos you want to keep. Three iQOO specifics: first, OTG is not a given on every model, and on Funtouch OS it is off by default. iQOO phones run Funtouch OS outside China — OriginOS on the China models — since iQOO is Vivo's sub-brand, and on Funtouch OS OTG is off unless you enable it in Settings > More settings > OTG (search Settings for "OTG" if you can't find it). Vivo's own FAQ says the switch turns itself off if it is not used in 5 minutes, so enable it with the drive already attached. Spec tables list USB Type-C 3.2 with OTG for the iQOO 13 and USB Type-C 2.0 with OTG for the iQOO 12, the Neo 10, and the Z10 Turbo Pro. If the phone ignores the drive, check Settings > Storage. Second, iQOO ships Vivo's apps, so the stock file manager is File Manager — a category-based browser (Images, Videos, Audio, Documents, Downloads) — which handles the phone's internal storage and connected external storage, and iQOO camera photos live in DCIM/Camera — and whether your model has a microSD slot varies by model, so check your own model's specs rather than assuming one either way; a USB drive is the plug-in storage that works on every model. Third, iQOO phones sold outside China ship with Google Play, so SnapDisk installs from the v0.1.2 APK on the GitHub release page today and from Play once the listing is live — there is no sideload-only situation here. One format note: drives formatted FAT32 can't hold a single file over 4 GB. That only matters for very long videos — SnapDisk skips those files and lists them instead of failing the whole backup. A drive formatted exFAT has no such limit.

Method 1: SnapDisk (one tap, background copy)

SnapDisk is a free Android app that does exactly this job and nothing else. Install it from the v0.1.2 APK (it's not on Google Play yet), then:

  1. Enable OTG first. On Funtouch OS OTG is off by default: go to Settings > More settings > OTG and turn it on — or search Settings for "OTG" if you can't find it — with the drive already attached, because Vivo's own FAQ says the switch turns itself off if it is not used in 5 minutes. Spec tables list USB Type-C 3.2 with OTG for the iQOO 13 and USB Type-C 2.0 with OTG for the iQOO 12, the Neo 10, and the Z10 Turbo Pro.
  2. Plug in the USB drive. Most OTG models mount it straight away — look for a "USB storage added" notification. If nothing appears, check Settings > Storage, and check the OTG switch is still on — it turns itself off if it is not used in 5 minutes.
  3. Open SnapDisk and check the folders. The app opens to a settings screen with a From folder and a To folder, each with a folder picker. The defaults are already right for most people: From /sdcard/DCIM (your camera photos — iQOO camera photos live in DCIM/Camera), To /disk/DCIM on the drive. If your photos live somewhere else, tap the From picker and choose that folder — the picker is the Android system folder picker, and the app keeps access to it.
  4. Tap Backup. SnapDisk offers a backup in a notification when the drive connects: "External storage is connected. Backup photos?" Tap it and your whole library copies oldest-first — your earliest photos first — in the background, while you use the phone normally. The copy mirrors the source folder structure on the drive, so DCIM stays DCIM.
  5. Watch the progress notification — real percent, copied / total size, speed, and time left — with Pause and Stop. You can pause and resume any time.
  6. Wait for "Backup complete." Every file is size-verified after copying, so the counts are proof, not a promise. Files that already copied are never copied twice — so if the free 5 GB per-run limit stops a big library partway, just run it again and it picks up where it left off.

The copies are the original files. SnapDisk streams each file byte-for-byte from the phone to the drive — the code reads the file and writes the same bytes out, with no decode, no recompression, and no resize — and then checks that the copy on the drive is the same size as the original. Other apps copy originals byte-for-byte too; what SnapDisk adds is the automated whole-library run: oldest-first order, progress with Pause and Stop, resume where it stopped, and skip-if-already-copied on the next run. If a file is corrupt or too big for FAT32, it's retried once, then skipped with its reason listed — it never stalls the whole backup. The free version backs up manually, up to 5 GB per backup run, with no ads, no account, and no cloud. SnapDisk Pro is a one-time $9.99 purchase (no subscription) that starts the backup automatically when you plug in a disk and removes the size limit. The app has no internet permission, so your photos physically cannot leave your device.

Method 2: File Manager (the stock route, no app needed)

iQOO phones ship with File Manager — the Funtouch OS file manager — as the stock file manager, and it can copy your photos to the USB drive: 1. Enable OTG first: Settings > More settings > OTG (search for "OTG" if you can't find it), with the drive already attached — Vivo's own FAQ says the switch turns itself off if it is not used in 5 minutes. 2. Plug in the USB drive — a notification should appear saying "USB storage added"; tap it to open the drive. If nothing appears, check Settings > Storage and check the OTG switch is still on. 3. Open File Manager and confirm the USB drive shows up under external storage. 4. Go back to Internal storage, DCIM, Camera, where your camera photos live. 5. Select the photos (long-press the first, tap the rest, or select all). 6. Tap Copy, then select the USB drive, and wait for the copy to finish — don't unplug the drive until File Manager says it's done. Eject the drive from the notification or from Settings > Storage before unplugging it. Use Copy, not Move: Move deletes the originals as it goes, so a bumped cable halfway through loses photos. This works fine for a one-off copy. Its limits are the reason SnapDisk exists: you pick files one by one, there is no progress detail beyond a spinner, no resume if you unplug mid-copy, no verification that every file actually arrived, and you have to repeat the whole manual selection next time photos pile up. For a library that grows every day, the app's oldest-first background copy is the calmer option.

Method 3: iQOO's own tools (iQOO Cloud, Google Photos, and Google backup — not phone-to-USB)

If you want iQOO's own route, know what each tool actually does — iQOO has no phone-to-USB backup of its own; the routes on an iQOO phone are iQOO Cloud (vivo Cloud) and Google's, plus PC tools, and none of them writes your photos as plain files to a USB drive. iQOO Cloud Backup is the official cloud backup, powered by vivo's cloud service: sign in with a vivo account and it backs the phone up to vivo's servers — contacts, messages, photos, settings, and app data — and restores them on another iQOO or Vivo phone. It is a real backup — but it lives on vivo's servers, needs a vivo account and a connection, its free storage is limited so a large photo library needs a paid plan, and it still doesn't give you a folder of photo files on a USB drive. Google Photos is Google's own photo backup app: open Photos, tap your profile picture, Photos settings, Backup, and turn Backup on — it automatically backs up photos to your Google account, with 15 GB free with every Google account. Your iQOO's default gallery app is the Albums app, not Google Photos — but either way it is a cloud backup, not a USB copy, and photos sync through Google Photos instead. Google backup is the route the iQOO guides point to first after iQOO Cloud: Settings > Google > Backup, Back up by Google One on — it backs the phone up to your Google account so you can restore app settings and data to a new phone. It is a real backup — but the backup lives in Google's cloud and restores to a phone, not a folder of photo files on a USB drive you can plug into any computer and open. vivo Mobile Assistant is Vivo's PC tool: install it on the computer, connect the phone with a USB cable, and back the phone up to the PC — but that needs a PC in between, and the backup lands on the PC, not on a USB drive. EasyShare is Vivo's phone-switching tool: it moves contacts, messages, photos, and more from an old phone to a new one, or backs the phone up to a PC — but it needs a second phone or a PC on the other end, and it moves data to that device, not to a USB drive. All of them work fine for what they are. Their limit, for photos specifically: none of them gives you a folder of plain photo files on a USB drive you can plug into any computer and open. If what you want is a copy of your photos you can open anywhere, Method 1 or 2 is the route — that is the gap this article fills, as of November 17, 2026.

What this does not do

A few honest limits, so the automatic copy is not oversold:

  • Photos and videos only. SnapDisk copies image and video files. Documents, voice notes, and anything that isn't a photo or video is skipped — Google backup is the tool if you want contacts, messages, and settings in the same backup, not just photos.
  • Only the folder you pick. By default that's DCIM — your camera photos. Photos in other folders (Downloads, app folders) only copy if you point the From folder at them, or at a parent folder that contains them.
  • Free 5 GB per run. A library bigger than 5 GB stops at the cap; run it again and it picks up where it stopped. Pro ($9.99, one-time) removes the limit and starts the backup automatically when you plug in a disk.
  • Files over 4 GB on FAT32 are skipped. Very long videos on a FAT32 drive are listed with their reason instead of failing the backup. Reformat the drive to exFAT if you need them.
  • It never deletes. SnapDisk only copies. Freeing space on the phone is copy, check the copy on the drive, then delete the originals yourself — never the other way round.
  • No OTG, no USB backup. On a model without working OTG — spec tables list OTG for the 13, 12, Neo 10, and Z10 Turbo Pro, but check your own model's specs before buying an adapter — a USB drive may simply never appear, and no app can change that. The cloud routes (iQOO Cloud, Google Photos, and Google backup) are the backup for those phones.

What to avoid

  • Buying an adapter before checking OTG. Not every iQOO phone is confirmed to have OTG — check your own model's specs first, or the drive will never appear no matter what you plug in.
  • Forgetting the OTG switch. On Funtouch OS OTG is off by default, and Vivo's own FAQ says the switch turns itself off if it is not used in 5 minutes — so a drive that worked yesterday can be ignored today. Enable it in Settings > More settings > OTG with the drive already attached. If there is no OTG setting at all, the phone may not support OTG.
  • Mistaking a cloud backup for a photo copy. iQOO Cloud, Google backup, and Google Photos back your phone up to vivo's or Google's servers — if you want to plug the drive into a computer and open the pictures, you need a plain copy, that is Method 1 or 2, not a cloud backup.
  • Mistaking a PC tool for a phone-to-USB copy. Drag-and-drop through a computer works — but it needs the PC in between. If the phone and the drive are all you have, a phone-to-USB copy is the route, not a desktop tool.
  • Mistaking a PC backup for a USB backup. vivo Mobile Assistant and Coolmuster Android Backup Manager back your iQOO phone up to a computer — a real backup, but it lands on the PC, not on a USB drive you can plug into any computer and open.
  • PC-only tools when you have no computer. Drag-and-drop through a Windows PC works — but it needs the PC in between. If the phone and the drive are all you have, a phone-to-USB copy is the route — that is the gap this article fills, as of November 17, 2026.
  • Cloud backup dressed as USB backup. If the app needs an account and an upload before your photos are safe, that's a cloud subscription with a USB step. Your photos sit on someone else's server, and the backup stops working the day you stop paying. On iQOO the cloud routes are iQOO Cloud, Google Photos, and Google backup — and Google Photos' "Storage saver" setting compresses photos, which is the one place quality actually gets lost.
  • Deleting before verifying. A backup is only a backup once you've confirmed the copy. Copy, open a few photos on the drive, then delete from the phone — never the other way round. SnapDisk only copies — it never deletes — so the delete step is always yours, and always after the check.
  • Moving instead of copying. The file manager's Move option copies and then deletes the originals in one step. If the copy fails halfway, photos are already gone from the phone. Copy first, verify, then delete.
  • Unplugging mid-copy. Pulling a USB drive out while files are still writing can corrupt the file in flight. Wait for the copy to finish, or pause it first — SnapDisk's Stop button exists for exactly this.

Rule of thumb: if you have to pick the files yourself, it isn't a backup — it's a chore you will skip. Automate the copy, check it on the drive, then delete from the phone.
