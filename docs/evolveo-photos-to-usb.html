What you need

An Evolveo StrongPhone that can run SnapDisk — the G9 runs Android 10 with USB OTG listed, and the G5 runs Android 9.0 with a USB-C port, so a USB-C flash drive plugs straight into either of them, while a regular USB-A drive needs an OTG adapter: USB-C on the G5 and the G9, micro-USB on the G4 if it turns out to run Android 7.0 or later — and enough space on the drive for the photos you want to keep. Method 1: SnapDisk (one tap, background copy)

SnapDisk is a free Android app that does exactly this job and nothing else. Install it from the v0.1.2 APK (it's not on Google Play yet), then:

  1. Plug in the USB drive. It mounts on plug-in on most Android phones with USB host support — look for a "USB storage added" notification. If nothing appears, check Settings > Storage for the drive. OTG support is confirmed in the sources I found on the G9 and the G4, but unconfirmed on the G5 — so on the G5 the drive mounting is the test itself: if it appears in Settings > Storage, the phone hosts drives and the rest of this method works; if it never appears, the phone does not host drives and Method 4 is the route. The G9 runs Android 10 and the G5 runs Android 9.0, so SnapDisk installs on either of them; the G4 needs an Android version check first, and the Q5 and the Q8 LTE cannot run it at all.
  2. Open SnapDisk and check the folders. The app opens to a settings screen with a From folder and a To folder, each with a folder picker. The defaults are already right for most people: From /sdcard/DCIM (your camera photos — Evolveo StrongPhone camera photos live in DCIM/Camera), To /disk/DCIM on the drive. If your photos live somewhere else, tap the From picker and choose that folder — the picker is the Android system folder picker, and the app keeps access to it.
  3. Tap Backup. SnapDisk offers a backup in a notification when the drive connects: "External storage is connected. Backup photos?" Tap it and your whole library copies oldest-first — your earliest photos first — in the background, while you use the phone normally. The copy mirrors the source folder structure on the drive, so DCIM stays DCIM.
  4. Watch the progress notification — real percent, copied / total size, speed, and time left — with Pause and Stop. You can pause and resume any time.
  5. Wait for "Backup complete." Every file is size-verified after copying, so the counts are proof, not a promise. Files that already copied are never copied twice — so if the free 5 GB per-run limit stops a big library partway, just run it again and it picks up where it left off.

The copies are the original files. SnapDisk streams each file byte-for-byte from the phone to the drive — the code reads the file and writes the same bytes out, with no decode, no recompression, and no resize — and then checks that the copy on the drive is the same size as the original. Other apps copy originals byte-for-byte too; what SnapDisk adds is the automated whole-library run: oldest-first order, progress with Pause and Stop, resume where it stopped, and skip-if-already-copied on the next run. If a file is corrupt or too big for FAT32, it's retried once, then skipped with its reason listed — it never stalls the whole backup. The free version backs up manually, up to 5 GB per backup run, with no ads, no account, and no cloud. SnapDisk Pro is a one-time $9.99 purchase (no subscription) that starts the backup automatically when you plug in a disk and removes the size limit. The app has no internet permission, so your photos physically cannot leave your device.

Method 2: a file manager (the stock route, no app needed)

A file manager can copy your photos to the USB drive — the YouTube guide's route is an OTG connection with the built-in file manager, and it is the manual route for external storage: 1. Plug in the USB drive — a notification should appear saying "USB storage added"; tap it to open the drive. If nothing appears, check Settings > Storage for the drive. 2. Open the file manager (Files by Google on Evolveo StrongPhone phones) and confirm the USB drive shows up under storage devices. 3. Go back to Internal storage, DCIM, Camera, where your camera photos live. 4. Select the photos (long-press the first, tap the rest, or select all). 5. Tap Copy, then select the USB drive, and wait for the copy to finish — don't unplug the drive until the file manager says it's done. Eject the drive from the notification or from Settings > Storage before unplugging it. Use Copy, not Move: Move deletes the originals as it goes, so a bumped cable halfway through loses photos. This works fine for a one-off copy. Its limits are the reason SnapDisk exists: you pick files one by one, there is no progress detail beyond a spinner, no resume if you unplug mid-copy, no verification that every file actually arrived, and you have to repeat the whole manual selection next time photos pile up. For a library that grows every day, the app's oldest-first background copy is the calmer option.

Method 3: Evolveo's own tools (Google Photos, Google Drive, or a microSD card — not phone-to-USB)

If you want Evolveo's own route, know what each tool actually does — there is no Evolveo backup page pointing at a USB drive at all, and none of the stock tools writes your photos as plain files to a USB drive automatically. 1. Google Photos is Google's own photo backup app, and it is the stock photo backup on Evolveo StrongPhone Android phones: it automatically backs up photos to your Google account. It is a real backup — but it is a cloud backup, not a USB copy, and photos sync through Google Photos instead. 2. Google Drive is the cloud backup Android names by default — "on Android devices the default built-in service is Google Drive. With Google Drive you have 15Gb free" — it backs your data up to Google's cloud. It is a real backup — but it is a cloud backup, not a USB copy, and Google accounts only offer 15 GB of free storage. 3. Google backup is what Android itself names: personal settings back up to Google's servers with a Google account, and are restored to a new phone when you sign in with that account. It is a real backup — but it backs up settings, not a folder of photo files on a drive you hold. 4. A microSD card is the local option on the G5 and the G9 — both take a card up to 128 GB. It is a real local copy — but the card stays in the phone, and opening the card anywhere else needs a card reader. 5. A computer copy is the other way to move files off the phone — connect the phone to a computer with a USB cable and copy DCIM to the computer. It is a real backup — but it needs a PC in between, and the backup lands on the PC, not on a USB drive as plain files straight from the phone. None of them is a one-tap way to copy your camera roll to a drive. All of them work fine for what they are. Their limit, for photos specifically: none of them gives you a folder of plain photo files on a USB drive you can plug into any computer and open. If what you want is a copy of your photos you can open anywhere, Method 1 or 2 is the route — that is the gap this article fills, as of November 18, 2026.

What this does not do

A few honest limits, so the automatic copy is not oversold:

  • Photos and videos only. SnapDisk copies image and video files. Documents, voice notes, and anything that isn't a photo or video is skipped — Google backup is the tool if you want contacts, messages, and settings in the same backup, not just photos.
  • Only the folder you pick. By default that's DCIM — your camera photos. Photos in other folders (Downloads, app folders) only copy if you point the From folder at them, or at a parent folder that contains them.
  • Free 5 GB per run. A library bigger than 5 GB stops at the cap; run it again and it picks up where it stopped. Pro ($9.99, one-time) removes the limit and starts the backup automatically when you plug in a disk.
  • Files over 4 GB on FAT32 are skipped. Very long videos on a FAT32 drive are listed with their reason instead of failing the backup. Reformat the drive to exFAT if you need them.
  • It never deletes. SnapDisk only copies. Freeing space on the phone is copy, check the copy on the drive, then delete the originals yourself — never the other way round.
  • OTG support is unconfirmed on the G5. The G9 lists USB OTG support — mobilespecs lists "USB: yes v2.0 OTG" — and FindPare lists "USB OTG: Yes" for the G4, but no source I found mentions OTG on the G5 at all, so plug a drive in and check Settings > Storage on that model before relying on it. The drive mounting is the test.
  • The Q8 LTE's OTG support is disputed between sources. Alza's own description lists "microUSB OTG" for the Q8 LTE, while FindPare lists USB OTG as No for the same phone. The Q8's OTG is not leaned on here — and it cannot run SnapDisk anyway, since it runs Android 4.4.
  • The G4's Android version is unconfirmed. FindPare lists "USB OTG: Yes" for the G4, released December 2016, but no source I found states which Android version it runs — and the site itself says its information is "not ascertained". Check Settings > About phone on the G4 before installing: SnapDisk needs Android 7.0 or later.
  • Five Evolveo models cannot run SnapDisk at all. The Q5 runs Android 5.1 and the Q8 LTE runs Android 4.4 — both below SnapDisk's Android 7.0 minimum — and the Z4, the X5, and the Z6 are feature phones, not Android phones at all. On those phones the computer copy in Method 4 is the route.
  • The adapter differs by model. The G5 and the G9 have a USB Type-C port, so a USB-C flash drive plugs straight into either of them and a regular USB-A drive needs a USB-C OTG adapter on either of them. The G4, the Q5, and the Q8 LTE have a micro-USB port, so a regular USB-A drive needs a micro-USB OTG adapter on those models. A plain USB-C charging cable is not an OTG adapter: it connects the phone to a computer, which is the opposite direction.

What to avoid

  • Buying an adapter you don't need — or the wrong one. A USB-C flash drive plugs straight into the G5 and the G9, both of which have USB-C — so an adapter is only needed for a regular USB-A drive, and it must be a USB-C OTG adapter on those models, a micro-USB OTG adapter on the G4, the Q5, and the Q8 LTE. A plain USB-C charging cable is not an OTG adapter: it connects the phone to a computer, which is the opposite direction.
  • Mistaking a cloud backup for a photo copy. Google Drive and Google Photos back your phone up to Google's servers — if you want to plug the drive into a computer and open the pictures, you need a plain copy, that is Method 1 or 2, not a cloud backup.
  • Mistaking a PC tool for a phone-to-USB copy. A computer copy with a USB cable moves files to a computer — but it is a copy to a computer, and the backup lands on the PC. If the phone and the drive are all you have, a phone-to-USB copy is the route, not a desktop copy.
  • Mistaking a spec table or a manual page for a phone-to-USB guide. The G5 manual and the Evolveo StrongPhone spec pages are real Evolveo pages — but the manual only lists an Android version and a USB connector type, and the spec pages only list an Android version, a chipset, or a USB connector type. Neither of them describes copying your camera roll straight to a USB drive from the phone.
  • Mistaking OTG support on one model for OTG support on the other. The G9 lists USB OTG support and the G4 lists it too — but no source I found mentions OTG on the G5, and the Q8 LTE's OTG is disputed between sources. Test with a drive on the G5, and use Method 2 or 4 on that model if the drive never mounts.
  • Mistaking a microSD card copy for a USB backup. Copying DCIM to a microSD card is a real local copy — the G5 and the G9 take a card up to 128 GB — but the card stays in the phone, and opening it anywhere else needs a card reader; a USB drive plugs into any computer as it is.
  • PC-only tools when you have no computer. Drag-and-drop through a Windows PC works — but it needs the PC in between. If the phone and the drive are all you have, a phone-to-USB copy is the route — that is the gap this article fills, as of November 18, 2026.
  • Cloud backup dressed as USB backup. If the app needs an account and an upload before your photos are safe, that's a cloud subscription with a USB step. Your photos sit on someone else's server, and the backup stops working the day you stop paying. On an Evolveo StrongPhone the cloud routes are Google Photos and Google Drive — and Google Photos' "Storage saver" setting compresses photos, which is the one place quality actually gets lost.
  • Deleting before verifying. A backup is only a backup once you've confirmed the copy. Copy, open a few photos on the drive, then delete from the phone — never the other way round. SnapDisk only copies — it never deletes — so the delete step is always yours, and always after the check.
  • Moving instead of copying. The file manager's Move option copies and then deletes the originals in one step. If the copy fails halfway, photos are already gone from the phone. Copy first, verify, then delete.
  • Unplugging mid-copy. Pulling a USB drive out while files are still writing can corrupt the file in flight. Wait for the copy to finish, or pause it first — SnapDisk's Stop button exists for exactly this.

Rule of thumb: if you have to pick the files yourself, it isn't a backup — it's a chore you will skip. Automate the copy, check it on the drive, then delete from the phone.
