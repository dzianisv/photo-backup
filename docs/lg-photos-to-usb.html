What you need

An LG phone (Android 7.0 or later for SnapDisk); a USB drive your phone can read — a USB-C flash drive plugs straight into a late LG phone (G7, G8, V30 and later, Velvet, Wing, V60), or a regular USB drive with a USB-C OTG adapter; older LG phones with a Micro-USB port need a Micro-USB OTG adapter instead; and enough space on the drive for the photos you want to keep. Three LG specifics: first, there is no OTG switch to enable. Plug the drive in and the phone mounts it on its own — LG never shipped an OTG toggle. If the phone shows no reaction at all, check the USB notification: if it says the phone is charging a connected device, tap it and switch to file transfer. Second, LG left the phone business in April 2021 (wound down by July 31, 2021), so there will be no new LG phones and no new LG backup tools — and LG Mobile Switch, the phone-to-phone mover, is no longer updated and struggles on newer Android versions. The good news for storage: most LG phones have a microSD card slot, so a card is the other plug-in storage option if your phone has one — check your own model's specs. If your phone has no card in the slot, a USB drive is the plug-in storage you get. Third, LG phones ship with Google Play, so SnapDisk installs from the v0.1.2 APK on the GitHub release page today and from Play once the listing is live — there is no Huawei-style sideload-only situation here. One format note: drives formatted FAT32 can't hold a single file over 4 GB. That only matters for very long videos — SnapDisk skips those files and lists them instead of failing the whole backup. A drive formatted exFAT has no such limit.

Method 1: SnapDisk (one tap, background copy)

SnapDisk is a free Android app that does exactly this job and nothing else. Install it from the v0.1.2 APK (it's not on Google Play yet), then:

  1. Open SnapDisk and check the folders. The app opens to a settings screen with a From folder and a To folder, each with a folder picker. The defaults are already right for most people: From /sdcard/DCIM (your camera photos — LG camera photos live in DCIM/Camera), To /disk/DCIM on the drive. If your photos live somewhere else, tap the From picker and choose that folder — the picker is the Android system folder picker, and the app keeps access to it.
  2. Plug in the USB drive. No switch to enable first — LG mounts the drive on its own. SnapDisk offers a backup in a notification: "External storage is connected. Backup photos?"
  3. Tap Backup. Your whole library copies oldest-first — your earliest photos first — in the background, while you use the phone normally. The copy mirrors the source folder structure on the drive, so DCIM stays DCIM.
  4. Watch the progress notification — real percent, copied / total size, speed, and time left — with Pause and Stop. You can pause and resume any time.
  5. Wait for "Backup complete." Every file is size-verified after copying, so the counts are proof, not a promise. Files that already copied are never copied twice — so if the free 5 GB per-run limit stops a big library partway, just run it again and it picks up where it left off.

The copies are the original files. SnapDisk streams each file byte-for-byte from the phone to the drive — the code reads the file and writes the same bytes out, with no decode, no recompression, and no resize — and then checks that the copy on the drive is the same size as the original. Other apps copy originals byte-for-byte too; what SnapDisk adds is the automated whole-library run: oldest-first order, progress with Pause and Stop, resume where it stopped, and skip-if-already-copied on the next run. If a file is corrupt or too big for FAT32, it's retried once, then skipped with its reason listed — it never stalls the whole backup. The free version backs up manually, up to 5 GB per backup run, with no ads, no account, and no cloud. SnapDisk Pro is a one-time $9.99 purchase (no subscription) that starts the backup automatically when you plug in a disk and removes the size limit. The app has no internet permission, so your photos physically cannot leave your device.

Method 2: LG File Manager (the stock route, no app needed)

LG phones ship with LG's own File Manager (open it from Management, then File Manager), and it can copy your photos to the USB drive: 1. Plug in the USB drive — a notification should appear; tap it to open the drive. 2. Open File Manager and tap to select the storage location — confirm the USB drive shows up. 3. Go back to Internal storage, DCIM, Camera, where your camera photos live. 4. Select the photos (long-press the first, tap the rest, or select all). 5. Tap Copy, then select the USB drive, and wait for the copy to finish — don't unplug the drive until File Manager says it's done. Use Copy, not Move: Move deletes the originals as it goes, so a bumped cable halfway through loses photos. This works fine for a one-off copy. Its limits are the reason SnapDisk exists: you pick files one by one, there is no progress detail beyond a spinner, no resume if you unplug mid-copy, no verification that every file actually arrived, and you have to repeat the whole manual selection next time photos pile up. For a library that grows every day, the app's oldest-first background copy is the calmer option.

Method 3: LG's own tools (phone-to-phone or phone-to-PC — not phone-to-USB)

If you want LG's own route, know what each tool actually does — none of them writes your photos as plain files to a USB drive. LG Mobile Switch moves data from an old phone to a new LG phone over a USB cable, Wi-Fi, or an SD card — it is a migration tool, not a backup tool, and it needs a second phone on the other end. It is also no longer updated, and it struggles on newer Android versions. LG Bridge is PC software: install it on a Windows PC or Mac, plug the phone in with a USB cable, and back the phone up to the computer — a device backup to a PC, not a phone-to-USB copy. LG Backup (Settings, Backup & reset, LG Backup) backs the phone up to an SD card or the cloud — it writes a backup, not your photos as files, and you restore it through LG Backup on an LG phone. All three work fine for what they are. Their limit, for photos specifically: none of them gives you a folder of plain photo files on a USB drive you can plug into any computer and open. If what you want is a copy of your photos you can open anywhere, Method 1 or 2 is the route — that is the gap this article fills, as of November 16, 2026.

Method 4: through a computer (if you have one)

If a PC or Mac is handy, the old route still works: plug the LG phone into the computer with a USB cable, tap the USB notification and choose File transfer (by default an LG phone charges only) — and drag the DCIM folder onto the USB drive, or use LG Bridge to back the phone up to the PC first. This works fine, and it is the only route above that needs a second device in between. If the phone and the drive are all you have, Method 1 or 2 is the route — that is the gap this article fills, as of November 16, 2026.

What this does not do

A few honest limits, so the automatic copy is not oversold:

  • Photos and videos only. SnapDisk copies image and video files. Documents, voice notes, and anything that isn't a photo or video is skipped — LG Backup is the tool if you want contacts, messages, and settings in the same backup, not just photos.
  • Only the folder you pick. By default that's DCIM — your camera photos. Photos in other folders (Downloads, app folders) only copy if you point the From folder at them, or at a parent folder that contains them.
  • Free 5 GB per run. A library bigger than 5 GB stops at the cap; run it again and it picks up where it stopped. Pro ($9.99, one-time) removes the limit and starts the backup automatically when you plug in a disk.
  • Files over 4 GB on FAT32 are skipped. Very long videos on a FAT32 drive are listed with their reason instead of failing the backup. Reformat the drive to exFAT if you need them.
  • It never deletes. SnapDisk only copies. Freeing space on the phone is copy, check the copy on the drive, then delete the originals yourself — never the other way round.

What to avoid

  • Hunting for an OTG switch that isn't there. LG has no OTG toggle — that is a OnePlus/Xiaomi thing. If your LG phone ignores a drive, the switch is not the problem: check the cable or adapter, check the USB notification, and check the drive is formatted exFAT or FAT32 — stock Android cannot mount NTFS drives.
  • Mistaking a backup package for a photo copy. LG Backup writes a backup to an SD card or the cloud, and LG Bridge writes a backup to the computer — not your photos as files. If you want to plug the drive into a computer and open the pictures, you need a plain copy — that is Method 1 or 2, not LG Backup or LG Bridge.
  • PC-only tools when you have no computer. Drag-and-drop through a Windows PC, or LG Bridge, works — but both need the PC in between. If the phone and the drive are all you have, a phone-to-USB copy is the route — that is the gap this article fills, as of November 16, 2026.
  • Cloud backup dressed as USB backup. If the app needs an account and an upload before your photos are safe, that's a cloud subscription with a USB step. Your photos sit on someone else's server, and the backup stops working the day you stop paying. On LG the cloud route is Google Photos — and its "Storage saver" setting compresses photos, which is the one place quality actually gets lost.
  • Deleting before verifying. A backup is only a backup once you've confirmed the copy. Copy, open a few photos on the drive, then delete from the phone — never the other way round. SnapDisk only copies — it never deletes — so the delete step is always yours, and always after the check.
  • Moving instead of copying. The file manager's Move option copies and then deletes the originals in one step. If the copy fails halfway, photos are already gone from the phone. Copy first, verify, then delete.
  • Unplugging mid-copy. Pulling a USB drive out while files are still writing can corrupt the file in flight. Wait for the copy to finish, or pause it first — SnapDisk's Stop button exists for exactly this.

Rule of thumb: if you have to pick the files yourself, it isn't a backup — it's a chore you will skip. Automate the copy, check it on the drive, then delete from the phone.
