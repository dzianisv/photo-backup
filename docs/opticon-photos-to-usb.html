Method 1: SnapDisk (one tap, background copy)

SnapDisk is a free Android app that does exactly this job and nothing else. Install it from the v0.1.2 APK (it's not on Google Play yet), then:

  1. Check your model can run SnapDisk. The H-35 runs Android 11 and the H-31 and the H-33 run Android 9 — all three clear the Android 7.0 minimum, so SnapDisk installs on all of them. The exception is the rest of the H-series — the H-28 and the H-29 run Android 6.0.1, the H-27 runs Android 4.2.2, and the H-32 runs Windows Embedded Compact 7, the H-21 runs Windows Mobile 6.5, the H-19A runs Windows Mobile 6.0 Professional, and the H-25 runs Windows CE 6.0 Professional — which cannot run SnapDisk at all, so Method 4 is the route on those units. Check Settings > About phone if you are unsure which Android version your unit runs.
  2. Plug in the USB drive. A USB-C flash drive plugs straight into the USB-C port on the H-35, and a regular USB-A drive needs a USB-C OTG adapter there. On the H-31 and the H-33 the port differs by source — Opticon's datasheet box contents list a USB C cable, manua.ls lists one Micro-USB 2.0 port — so check the port on your unit and buy the adapter that fits it. It mounts on plug-in on most Android devices with USB host support — look for a "USB storage added" notification. If nothing appears, check Settings > Storage for the drive. One Opticon wrinkle: no source found confirms OTG or host support on the H-31 or the H-33 at all, so on those models the drive mounting is the test — if the drive never appears in Settings > Storage, the device does not host drives and Method 4 is the route.
  3. Open SnapDisk and check the folders. The app opens to a settings screen with a From folder and a To folder, each with a folder picker. The defaults are already right for most people: From /sdcard/DCIM (your camera photos — Opticon camera photos live in DCIM/Camera), To /disk/DCIM on the drive. If your photos live somewhere else, tap the From picker and choose that folder — the picker is the Android system folder picker, and the app keeps access to it.
  4. Tap Backup. SnapDisk offers a backup in a notification when the drive connects: "External storage is connected. Backup photos?" Tap it and your whole library copies oldest-first — your earliest photos first — in the background, while you use the device normally. The copy mirrors the source folder structure on the drive, so DCIM stays DCIM.
  5. Watch the progress notification — real percent, copied / total size, speed, and time left — with Pause and Stop. You can pause and resume any time.
  6. Wait for "Backup complete." Every file is size-verified after copying, so the counts are proof, not a promise. Files that already copied are never copied twice — so if the free 5 GB per-run limit stops a big library partway, just run it again and it picks up where it left off.

The copies are the original files. SnapDisk streams each file byte-for-byte from the device to the drive — the code reads the file and writes the same bytes out, with no decode, no recompression, and no resize — and then checks that the copy on the drive is the same size as the original. Other apps copy originals byte-for-byte too; what SnapDisk adds is the automated whole-library run: oldest-first order, progress with Pause and Stop, resume where it stopped, and skip-if-already-copied on the next run. If a file is corrupt or too big for FAT32, it's retried once, then skipped with its reason listed — it never stalls the whole backup. The free version backs up manually, up to 5 GB per backup run, with no ads, no account, and no cloud. SnapDisk Pro is a one-time $9.99 purchase (no subscription) that starts the backup automatically when you plug in a disk and removes the size limit. The app has no internet permission, so your photos physically cannot leave your device.

Method 2: a file manager (the stock route, no app needed)

A file manager can copy your photos to the USB drive — the generic guides' route is an OTG connection with the built-in file manager, and it is the manual route for external storage: 1. Plug in the USB drive — a USB-C drive plugs straight into the USB-C port on the H-35, a regular USB-A drive needs a USB-C OTG adapter there, and on the H-31 and the H-33 the port differs by source (datasheet box lists a USB C cable, manua.ls lists Micro-USB 2.0), so check the port on your unit. A notification should appear saying "USB storage added"; tap it to open the drive. If nothing appears, check Settings > Storage for the drive. On the H-31 and the H-33, where no source confirms OTG, if the drive never appears, the device does not host drives and Method 4 is the route. 2. Open the file manager (Files by Google on the Android models) and confirm the USB drive shows up under storage devices. 3. Go back to Internal storage, DCIM, Camera, where your camera photos live. 4. Select the photos (long-press the first, tap the rest, or select all). 5. Tap Copy, then select the USB drive, and wait for the copy to finish — don't unplug the drive until the file manager says it's done. Eject the drive from the notification or from Settings > Storage before unplugging it. Use Copy, not Move: Move deletes the originals as it goes, so a bumped cable halfway through loses photos. This works fine for a one-off copy. Its limits are the reason SnapDisk exists: you pick files one by one, there is no progress detail beyond a spinner, no resume if you unplug mid-copy, no verification that every file actually arrived, and you have to repeat the whole manual selection next time photos pile up. For a library that grows every day, the app's oldest-first background copy is the calmer option. One note: the file-manager route works on the H-28, the H-29 and the H-27 too — it needs no app install, so the Android 7.0 minimum does not apply to it — but those units still need to host the drive, so the drive mounting is the test there as well, and the H-32, the H-21, the H-19A and the H-25 run Windows, so their file manager is the Windows one, not Files by Google.

Method 3: Opticon's own tools (Google Photos, Google Drive, or a microSD card — not phone-to-USB)

If you want Opticon's own route, know what each tool actually does — there is no Opticon backup page pointing at a USB drive at all, and none of the stock tools writes your photos as plain files to a USB drive automatically. 1. Google Photos is Google's own photo backup app, and it is the stock photo backup on Opticon handhelds: it automatically backs up photos to your Google account. It is a real backup — but it is a cloud backup, not a USB copy, and photos sync through Google Photos instead. 2. Google Drive is the cloud backup Android names by default — "on Android devices the default built-in service is Google Drive. With Google Drive you have 15Gb free" — it backs your data up to Google's cloud. It is a real backup — but it is a cloud backup, not a USB copy, and Google accounts only offer 15 GB of free storage. 3. Google backup is what Android itself names: personal settings back up to Google's servers with a Google account, and are restored to a new phone when you sign in with that account. It is a real backup — but it backs up settings, not a folder of photo files on a drive you hold. 4. A microSD card is the local option on the Android models — the H-35 takes a card up to 128 GB and the H-31 and the H-33 take a microSD card, with no capacity stated in the datasheet. It is a real local copy — but the card stays in the device, and opening the card anywhere else needs a card reader. 5. A computer copy is the other way to move files off the device — connect the handheld to a computer with a USB cable and copy DCIM from the device to the computer. It is a real backup — but it needs a PC in between, and the backup lands on the PC, not on a USB drive as plain files straight from the device. None of them is a one-tap way to copy your camera roll to a drive. All of them work fine for what they are. Their limit, for photos specifically: none of them gives you a folder of plain photo files on a USB drive you can plug into any computer and open. If what you want is a copy of your photos you can open anywhere, Method 1 or 2 is the route — that is the gap this article fills, as of November 18, 2026.

What this does not do

A few honest limits, so the automatic copy is not oversold:

  • Photos and videos only. SnapDisk copies image and video files. Documents, voice notes, and anything that isn't a photo or video is skipped — Google backup is the tool if you want contacts, messages, and settings in the same backup, not just photos.
  • Only the folder you pick. By default that's DCIM — your camera photos. Photos in other folders (Downloads, app folders) only copy if you point the From folder at them, or at a parent folder that contains them.
  • Free 5 GB per run. A library bigger than 5 GB stops at the cap; run it again and it picks up where it stopped. Pro ($9.99, one-time) removes the limit and starts the backup automatically when you plug in a disk.
  • Files over 4 GB on FAT32 are skipped. Very long videos on a FAT32 drive are listed with their reason instead of failing the backup. Reformat the drive to exFAT if you need them.
  • It never deletes. SnapDisk only copies. Freeing space on the device is copy, check the copy on the drive, then delete the originals yourself — never the other way round.
  • OTG is confirmed on only one of the three Android models that can run SnapDisk. The H-35 lists "USB3.1, Type-C, OTG" in its spec sheet — but no source found confirms OTG or host support on the H-31 or the H-33 at all. If the drive never appears in Settings > Storage on one of those models, the device does not host drives and Method 4 is the route.
  • The H-31/H-33 port differs by source. Opticon's datasheet box contents list a "USB C cable" for the H-31 and the H-33, while manua.ls lists one Micro-USB 2.0 port on the H-33 — check the port on your unit before buying an adapter: a USB-C flash drive plugs straight into a USB-C H-31 or H-33, a regular USB-A drive needs a USB-C OTG adapter there, and a Micro-USB H-31 or H-33 needs a Micro-USB OTG adapter instead.
  • No source found states the connector type on the H-28 or the H-29 at all. Their datasheets list USB in the communications but name no connector — and both run Android 6.0.1, below SnapDisk's Android 7.0 minimum, so the computer copy in Method 4 is the route on them regardless.
  • Most Opticon H-series models cannot run SnapDisk at all. The H-28 and the H-29 run Android 6.0.1 and the H-27 runs Android 4.2.2 — so on those units the computer copy in Method 4 is the route, not this article's one-tap method. The H-32 runs Windows Embedded Compact 7, the H-21 runs Windows Mobile 6.5, the H-19A runs Windows Mobile 6.0 Professional, and the H-25 runs Windows CE 6.0 Professional, not Android at all, so they cannot run SnapDisk either — and their file manager is the Windows one, so Method 2 on those units is a Windows copy, not Files by Google. The H-35 runs Android 11 and the H-31 and the H-33 run Android 9 — so every Android model that can run SnapDisk clears the minimum, and SnapDisk installs on all three. The blocker on this line is the host support, not the Android version.
  • The H-32 has no camera listed in its spec sheet. It is a barcode terminal with a 1D laser scanner or a 2D imager, a 2.8" QVGA touchscreen, and no camera — so there is no photo library to back up on it anyway, and it runs Windows Embedded Compact 7, not Android. Its Micro USB OTG is confirmed, but it is irrelevant to photos.
  • The H-21 has a color camera but runs Windows Mobile 6.5. Its datasheet lists a 2D CMOS imager and a color camera — but it runs Windows Mobile 6.5, not Android, so it cannot run SnapDisk, and the computer copy in Method 4 is the route.
  • No other Opticon H-series handheld model turned up in the sources found. This article covers only the H-35, the H-31, the H-33, the H-28, the H-29, the H-27, the H-32, the H-21, the H-19A and the H-25 — if your handheld is a different Opticon model, check Settings > About phone for its Android version and Settings > Storage for drive mounting, the same two tests used here.

A plain USB-C charging cable is not an OTG adapter: it connects the device to a computer, which is the opposite direction.

What to avoid

  • Buying an adapter you don't need — or the wrong one. A USB-C flash drive plugs straight into the H-35 — so no adapter is needed on it for a USB-C drive — while a regular USB-A drive needs a USB-C OTG adapter there. On the H-31 and the H-33 the port differs by source — the datasheet box contents list a USB C cable, manua.ls lists one Micro-USB 2.0 port — so check the port on your unit first. A plain USB-C charging cable is not an OTG adapter: it connects the device to a computer, which is the opposite direction.
  • Assuming a model hosts drives because another Opticon model does. The H-35 lists "USB3.1, Type-C, OTG" in its spec sheet — but no source found confirms it on the H-31 or the H-33, so test with a drive on your model, and use Method 2 or 4 on it if the drive never mounts.
  • Installing SnapDisk on an Opticon unit below Android 7.0. The H-28 and the H-29 run Android 6.0.1 and the H-27 runs Android 4.2.2 — and the H-32 runs Windows Embedded Compact 7, the H-21 runs Windows Mobile 6.5, the H-19A runs Windows Mobile 6.0 Professional, and the H-25 runs Windows CE 6.0 Professional — check Settings > About phone first: on any of those units the computer copy in Method 4 is the route, not this article's one-tap method.
  • Mistaking a cloud backup for a photo copy. Google Drive and Google Photos back your device up to Google's servers — if you want to plug the drive into a computer and open the pictures, you need a plain copy, that is Method 1 or 2, not a cloud backup.
  • Mistaking a PC tool for a phone-to-USB copy. A computer copy with a USB cable moves files to a computer — but it is a copy to a computer, and the backup lands on the PC. If the device and the drive are all you have, a phone-to-USB copy is the route, not a desktop copy.
  • Mistaking a spec table or a product page for a phone-to-USB guide. The Opticon spec sheets and product pages are real Opticon pages — but the spec sheets only list an Android version, a chipset, or a USB connector type, and the product pages only describe the hardware. Neither of them describes copying your camera roll straight to a USB drive from the device.
  • Mistaking a manual for a phone-to-USB guide. The H-35 user guide and the H-32 user guide are real Opticon documents — but neither describes copying your camera roll straight to a USB drive from the device.
  • Mistaking OTG support on one model for OTG support on the other. The H-35 lists "USB3.1, Type-C, OTG" in its spec sheet — but no source found confirms it on the H-31 or the H-33, so test with a drive on your model, and use Method 2 or 4 on it if the drive never mounts.
  • Mistaking a drive-locked app for a general backup. Photo Backup Stick DC is a real one-tap backup app — but it only works with genuine Photo Backup Stick OTG drives. If the drive you already own is any other brand, that app cannot use it: SnapDisk, Photos to USB, and FotoSafe work with any drive.
  • Mistaking a microSD card copy for a USB backup. Copying DCIM to a microSD card is a real local copy — the H-35 takes a card up to 128 GB and the H-31 and the H-33 take a microSD card, with no capacity stated in the datasheet — but the card stays in the device, and opening it anywhere else needs a card reader; a USB drive plugs into any computer as it is.
  • PC-only tools when you have no computer. Drag-and-drop through a Windows PC works — but it needs the PC in between. If the device and the drive are all you have, a phone-to-USB copy is the route — that is the gap this article fills, as of November 18, 2026.
  • Cloud backup dressed as USB backup. If the app needs an account and an upload before your photos are safe, that's a cloud subscription with a USB step. Your photos sit on someone else's server, and the backup stops working the day you stop paying. On an Opticon handheld the cloud routes are Google Photos and Google Drive — and Google Photos' "Storage saver" setting compresses photos, which is the one place quality actually gets lost.
  • Deleting before verifying. A backup is only a backup once you've confirmed the copy. Copy, open a few photos on the drive, then delete from the device — never the other way round. SnapDisk only copies — it never deletes — so the delete step is always yours, and always after the check.
  • Moving instead of copying. The file manager's Move option copies and then deletes the originals in one step. If the copy fails halfway, photos are already gone from the device. Copy first, verify, then delete.
  • Unplugging mid-copy. Pulling a USB drive out while files are still writing can corrupt the file in flight. Wait for the copy to finish, or pause it first — SnapDisk's Stop button exists for exactly this.

Rule of thumb: if you have to pick the files yourself, it isn't a backup — it's a chore you will skip. Automate the copy, check it on the drive, then delete from the device.
