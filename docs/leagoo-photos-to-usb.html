Method 1: SnapDisk — proven on sixteen

Method 1 is the one-tap version. It uses SnapDisk, the free backup app this site is about — SnapDisk. Free version: manual backup, up to 5 GB per run. Pro is a one-time $9.99 purchase and adds auto-backup on connect plus unlimited size. SnapDisk needs Android 7.0 or later, which thirty covered Leagoo phones clear — the lowest is Android 7.0 — so the app installs on those thirty, and the one-tap backup is proven on sixteen: each one lists USB OTG Yes.

  1. Check the Android version first. Settings > About phone > Android version. Thirty covered phones run Android 7.0 or newer — the oldest clear ones are the KIICAA Mix, KIICAA Power, M7, M9, S8, S8 Pro, T5, T5c, Z6 and Z7 on Android 7.0, and the newest, the M12, M13 and S11, run Android 9.0. If it says anything below 7.0, you are on one of the thirty-three below-floor phones — check the model name before buying a drive expecting the one-tap backup.
  2. Install SnapDisk. SnapDisk is not on Google Play yet — the listing is being prepared — so install the v0.1.2 APK from the GitHub release page. On the phone, allow installing from unknown sources when asked. It needs Android 7.0 or later, which thirty covered Leagoo phones clear — the lowest is Android 7.0 — so on a Leagoo phone the APK installs on those thirty, and the one-tap backup is proven on sixteen.
  3. Plug in the USB drive. On nine covered phones that is a USB-C flash drive plugged straight in — no adapter, no cable. On the fifty-three micro-USB models that is a micro-USB OTG adapter between the phone and the drive. A plain sync cable is the wrong cable: it connects a phone to a computer, not a drive to a phone.
  4. Look for the mount notification. On the sixteen proven phones Android notices the drive and offers it as storage, and SnapDisk picks it as the To folder. SnapDisk copies the photos byte-for-byte: the file on the drive is the same file the phone took, with the same pixels. There is no re-encoding step, so nothing is lost in the copy — the only place quality gets lost is a cloud backup with a "Storage saver" setting.

Method 2: the file manager and an OTG adapter

Method 2 is the manual version of the same thing — no app, just the phone's file manager and a drive. No source names Leagoo's bundled file manager, so this method says "the file manager" generically rather than naming one. It works on the sixteen proven phones, and on the eight mounting-test phones and the contested T5c if the drive shows up in Settings.

  1. Plug the drive into the phone. On nine covered phones that is a USB-C flash drive plugged straight in. On the fifty-three micro-USB models that is a micro-USB OTG adapter between the phone and the drive.
  2. Open the file manager and find the DCIM folder. Your camera photos live in the DCIM folder — on most phones that is Internal storage > DCIM > Camera. Screenshots live in Pictures > Screenshots, and WhatsApp photos in Android > media > com.whatsapp > WhatsApp > Media > WhatsApp Images.
  3. Select the photos and copy them to the drive. Long-press one photo, select the rest, tap Copy, navigate to the USB drive and tap Paste. Copy, not Move — see "What to avoid" below.
  4. Wait, then check. Copying takes time — thousands of photos can take half an hour or more. Open the drive in the file manager and count before you delete anything.

This is the same copy Method 1 does, done by hand. It copies the original files as they are — no re-encoding, no quality loss.

  • It does not work if the phone does not host a drive.   • It does not delete photos. A backup copies the photos to the drive; deleting the originals is a separate step, and only after you have checked the copy.
  • It does not back up your settings, contacts or messages. It backs up photos and videos — the files in your camera roll.

  • It does not compress or shrink your photos. The copy is the original file — the same pixels, the same size.

What to avoid

  • Don't move instead of copying. Move deletes the original as it goes — if the copy fails halfway, the photos are gone. Copy first, check the copy, then delete.
  • Don't unplug the drive until the copy is done. Unplugging mid-copy corrupts the files being written. Wait for the progress to finish, then eject the drive in Settings before pulling it out.
  • Don't buy a micro-USB adapter for a Type-C phone. Nine covered phones take USB Type-C — a USB-C flash drive plugs straight in, and the adapter is the wrong buy.
  • Don't buy a USB-C drive expecting it to plug into one of the fifty-three micro-USB phones. Those fifty-three are micro-USB, and a USB-C drive needs a micro-USB OTG adapter between them.
