What you need

A Vivo phone (Android 7.0 or later for SnapDisk); a USB drive your phone can read — a USB-C flash drive plugs straight into a modern Vivo phone (X, V, and recent Y series), or a regular USB drive with a USB-C OTG adapter; older Vivo phones with a Micro-USB port need a Micro-USB OTG adapter instead; and enough space on the drive for the photos you want to keep. Three Vivo specifics: first, turn on OTG before you plug anything in. Funtouch OS puts the switch in Settings — More settings > OTG — and if you can't find it, search Settings for "OTG". Vivo's own FAQ says the switch turns itself off if it is not used in 5 minutes, to save power, so enable it and plug the drive in straight away; if the phone ignores the drive, the switch has probably timed out — turn it on again with the drive already attached. Not every Vivo phone has OTG at all, so if there is no OTG setting anywhere, the phone may not support it. Second, Vivo's stock file manager is File Manager, a category-based browser (Images, Videos, Audio, Documents, Downloads), and Vivo camera photos live in DCIM/Camera — and whether your model has a microSD slot varies by model (budget Y and T series phones include one), so check your own model's specs rather than assuming one either way; a USB drive is the plug-in storage that works on every model. Third, Vivo phones ship with Google Play, so SnapDisk installs from the v0.1.2 APK on the GitHub release page today and from Play once the listing is live — there is no Huawei-style sideload-only situation here. One format note: drives formatted FAT32 can't hold a single file over 4 GB. That only matters for very long videos — SnapDisk skips those files and lists them instead of failing the whole backup. A drive formatted exFAT has no such limit.

Method 1: SnapDisk (one tap, background copy)

SnapDisk is a free Android app that does exactly this job and nothing else. Install it from the v0.1.2 APK (it's not on Google Play yet), then:

  1. Turn on OTG. Open Settings > More settings > OTG and switch it on — or search Settings for "OTG" if you can't find it. Do this right before plugging the drive in — Vivo's own FAQ says the switch turns itself off if it is not used in 5 minutes.
  2. Open SnapDisk and check the folders. The app opens to a settings screen with a From folder and a To folder, each with a folder picker. The defaults are already right for most people: From /sdcard/DCIM (your camera photos — Vivo camera photos live in DCIM/Camera), To /disk/DCIM on the drive. If your photos live somewhere else, tap the From picker and choose that folder — the picker is the Android system folder picker, and the app keeps access to it.
  3. Plug in the USB drive. SnapDisk offers a backup in a notification: "External storage is connected. Backup photos?"
  4. Tap Backup. Your whole library copies oldest-first — your earliest photos first — in the background, while you use the phone normally. The copy mirrors the source folder structure on the drive, so DCIM stays DCIM.
  5. Watch the progress notification — real percent, copied / total size, speed, and time left — with Pause and Stop. You can pause and resume any time.
  6. Wait for "Backup complete." Every file is size-verified after copying, so the counts are proof, not a promise. Files that already copied are never copied twice — so if the free 5 GB per-run limit stops a big library partway, just run it again and it picks up where it left off.

The copies are the original files. SnapDisk streams each file byte-for-byte from the phone to the drive — the code reads the file and writes the same bytes out, with no decode, no recompression, and no resize — and then checks that the copy on the drive is the same size as the original. Other apps copy originals byte-for-byte too; what SnapDisk adds is the automated whole-library run: oldest-first order, progress with Pause and Stop, resume where it stopped, and skip-if-already-copied on the next run. If a file is corrupt or too big for FAT32, it's retried once, then skipped with its reason listed — it never stalls the whole backup. The free version backs up manually, up to 5 GB per backup run, with no ads, no account, and no cloud. SnapDisk Pro is a one-time $9.99 purchase (no subscription) that starts the backup automatically when you plug in a disk and removes the size limit. The app has no internet permission, so your photos physically cannot leave your device.

Method 2: File Manager (the stock route, no app needed)

Vivo phones ship with File Manager as the stock file manager, and it can copy your photos to the USB drive: 1. Turn on OTG in Settings > More settings > OTG (search for "OTG" if you can't find it), then plug in the USB drive — a notification should appear; tap it to open the drive. 2. Open File Manager and confirm the USB drive shows up as a storage location. 3. Go back to Internal storage, DCIM, Camera, where your camera photos live. 4. Select the photos (long-press the first, tap the rest, or select all). 5. Tap Copy, then select the USB drive, and wait for the copy to finish — don't unplug the drive until File Manager says it's done. Use Copy, not Move: Move deletes the originals as it goes, so a bumped cable halfway through loses photos. This works fine for a one-off copy. Its limits are the reason SnapDisk exists: you pick files one by one, there is no progress detail beyond a spinner, no resume if you unplug mid-copy, no verification that every file actually arrived, and you have to repeat the whole manual selection next time photos pile up. For a library that grows every day, the app's oldest-first background copy is the calmer option.

Method 3: Vivo's own tools (phone-to-phone, phone-to-PC, or to the cloud — not phone-to-USB)

If you want Vivo's own route, know what each tool actually does — none of them writes your photos as plain files to a USB drive. EasyShare is Vivo's official phone-switching and sharing tool: it moves contacts, messages, photos, videos, and more from an old phone to a new Vivo — open EasyShare, tap Send on one phone and Accept on the other — but it needs a second phone on the other end, and it moves data to that phone, not to a USB drive. EasyShare can also back the phone up to a PC: install EasyShare on the computer, connect the phone and computer over a USB cable or Wi-Fi, and choose backup/restore — but that needs a PC in between, and the backup lands on the PC, not on a USB drive. vivo Cloud is Vivo's official cloud service: sign in with a vivo account and it backs the phone up to Vivo's servers, with 5 GB free and an automatic backup about every 7 days when the phone is charging, on Wi-Fi, and locked — but it is a cloud backup, not a USB copy, and the device backup covers system data, call logs, messages, and apps; photos sync through the Albums app or Google Photos instead. Both work fine for what they are. Their limit, for photos specifically: none of them gives you a folder of plain photo files on a USB drive you can plug into any computer and open. If what you want is a copy of your photos you can open anywhere, Method 1 or 2 is the route — that is the gap this article fills, as of November 16, 2026.

Method 4: through a computer (if you have one)

If a PC or Mac is handy, the old route still works: plug the Vivo phone into the computer with a USB cable, tap the USB notification and choose File transfer (by default a Vivo phone charges only) — and drag the DCIM folder onto the USB drive, or use a PC tool like MobiKin Assistant or MobileTrans, which both back a Vivo phone up to a PC in one click. This works fine, and it is the only route above that needs a second device in between. If the phone and the drive are all you have, Method 1 or 2 is the route — that is the gap this article fills, as of November 16, 2026.

What this does not do

A few honest limits, so the automatic copy is not oversold:

  • Photos and videos only. SnapDisk copies image and video files. Documents, voice notes, and anything that isn't a photo or video is skipped — vivo Cloud is the tool if you want contacts, messages, and settings in the same backup, not just photos.
  • Only the folder you pick. By default that's DCIM — your camera photos. Photos in other folders (Downloads, app folders) only copy if you point the From folder at them, or at a parent folder that contains them.
  • Free 5 GB per run. A library bigger than 5 GB stops at the cap; run it again and it picks up where it stopped. Pro ($9.99, one-time) removes the limit and starts the backup automatically when you plug in a disk.
  • Files over 4 GB on FAT32 are skipped. Very long videos on a FAT32 drive are listed with their reason instead of failing the backup. Reformat the drive to exFAT if you need them.
  • It never deletes. SnapDisk only copies. Freeing space on the phone is copy, check the copy on the drive, then delete the originals yourself — never the other way round.

What to avoid

  • Plugging the drive in before turning OTG on. On Vivo, the OTG switch is off by default and turns itself off if it is not used in 5 minutes — that is a Funtouch OS thing, not a fault in the drive. If your Vivo phone ignores a drive, go to Settings > More settings > OTG, turn the switch on, and plug the drive in straight away. If there is no OTG setting at all, the phone may not support OTG.
  • Mistaking a phone-to-phone move for a photo copy. EasyShare moves your photos to a new phone or backs them up to a PC, and vivo Cloud moves them to Vivo's servers — none writes your photos as files to a USB drive. If you want to plug the drive into a computer and open the pictures, you need a plain copy — that is Method 1 or 2, not EasyShare or vivo Cloud.
  • PC-only tools when you have no computer. Drag-and-drop through a Windows PC, or MobiKin Assistant, works — but both need the PC in between. If the phone and the drive are all you have, a phone-to-USB copy is the route — that is the gap this article fills, as of November 16, 2026.
  • Cloud backup dressed as USB backup. If the app needs an account and an upload before your photos are safe, that's a cloud subscription with a USB step. Your photos sit on someone else's server, and the backup stops working the day you stop paying. On Vivo the cloud route is Google Photos or vivo Cloud — and Google Photos' "Storage saver" setting compresses photos, which is the one place quality actually gets lost.
  • Deleting before verifying. A backup is only a backup once you've confirmed the copy. Copy, open a few photos on the drive, then delete from the phone — never the other way round. SnapDisk only copies — it never deletes — so the delete step is always yours, and always after the check.
  • Moving instead of copying. The file manager's Move option copies and then deletes the originals in one step. If the copy fails halfway, photos are already gone from the phone. Copy first, verify, then delete.
  • Unplugging mid-copy. Pulling a USB drive out while files are still writing can corrupt the file in flight. Wait for the copy to finish, or pause it first — SnapDisk's Stop button exists for exactly this.

Rule of thumb: if you have to pick the files yourself, it isn't a backup — it's a chore you will skip. Automate the copy, check it on the drive, then delete from the phone.
