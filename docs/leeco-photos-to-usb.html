Android 6.0.1 sits below SnapDisk's 7.0 floor, below VaultDrive's 8.0 floor and below FotoSafe's 9.0 floor. No source found states whether this model takes a microSD card at all. This is a definite answer on OTG — and it is Yes: Ubergizmo lists USB 2.0 and USB OTG for its Type-C connector. The drive mounts, but SnapDisk does not install on Android 6.0.1, so the file-manager copy in Method 2 is the route.

Method 1: SnapDisk — blocked on stock firmware, one custom-ROM exception

On stock firmware, SnapDisk does not install on any LeEco phone: every covered model runs Android 6.0.1 or older, below SnapDisk's Android 7.0 minimum, so the installer refuses it. The Android 7.1 update LeEco was testing — EUI 6.0.28 for the Le 2, Le 2 Pro, Le Pro 3, Le Max 2 and Le S3 — never shipped, and the Le Pro 3 and the Le S3 stayed on Android 6.0.1. There is exactly one documented exception:

  1. Check your Android version first. Settings > About phone shows the version. If it says 6.0.1 or lower, SnapDisk will not install — do not buy a drive expecting the one-tap backup. If it says 7.1.1, your phone is already running a custom ROM: skip to step 3.
  2. On a Le Pro 3 only, LineageOS 14.1 is the documented route past the floor. LineageOS 14.1 is a custom firmware based on Android 7.1.1, and the Le Pro 3 is listed on the official LineageOS download page. Installing it needs an unlocked bootloader and a custom recovery, and it wipes the phone completely — back up everything first, which is the point of this article, so copy your photos to a computer before you start, using Method 3. No other covered model has a documented custom-ROM route in the sources found: the Le 2, Le 2 Pro, Le Max 2 and Le S3 were in the same unshipped 7.1 test, but no source found documents a working 7.x ROM for them.
  3. On a Le Pro 3 running LineageOS 14.1, install SnapDisk from the GitHub APK. The Play listing is being prepared, so until then install the v0.1.2 APK from the GitHub release page. It installs on Android 7.0 and later, so it installs on a Le Pro 3 on Android 7.1.1 — and that phone lists USB OTG Yes, so the one-tap backup to a drive is proven on it, and only on it.
  4. Plug in the USB drive. The Le Pro 3 takes USB Type-C, so a USB-C flash drive plugs straight in, or a regular USB drive needs a USB-C OTG adapter, with the OTG wiring inside it — a plain sync cable is the wrong cable, it connects the phone to a computer, which is the opposite direction.
  5. Look for the mount notification. Tap Backup in the notification and SnapDisk copies the whole camera roll oldest-first in the background, showing progress, speed and ETA, with Pause and Stop. The free version backs up manually up to 5 GB per run; Pro is a one-time $9.99 purchase for auto-backup on connect and unlimited size.
  6. Check the copy, then delete from the phone if you need the space. SnapDisk verifies every file's size after copying, but open a few photos on the drive yourself before deleting anything.

This is the only method in this article that takes the whole library in one tap, with progress, pause, resume and verification — and on stock firmware it works on none of the eleven. Its limits are the version floor itself: SnapDisk needs Android 7.0, no stock LeEco phone has it, and the custom-ROM route is documented for one model only, the Le Pro 3, and it wipes the phone to get there.

The copies are the original files. SnapDisk streams each file byte-for-byte from the device to the drive — the code reads the file and writes the same bytes out, with no decode, no recompression, and no resize — and then checks that the copy on the drive is the same size as the original. Other apps copy originals byte-for-byte too; what SnapDisk adds is the automated whole-library run: oldest-first order, progress with Pause and Stop, resume where it stopped, and skip-if-already-copied on the next run. If a file is corrupt or too big for FAT32, it's retried once, then skipped with its reason listed — it never stalls the whole backup. The free version backs up manually, up to 5 GB per backup run, with no ads, no account, and no cloud. SnapDisk Pro is a one-time $9.99 purchase (no subscription) that starts the backup automatically when you plug in a disk and removes the size limit. The app has no internet permission, so your photos physically cannot leave your device.

Method 2: the file manager and an OTG adapter (works wherever the drive mounts)

This is the stock route, and the only phone route that works on most LeEco phones at all. It works if — and only if — your phone hosts the drive. On the six that list OTG Yes — the Le Max, Le 2, Le 2 Pro, Le Max 2, Le Pro 3 and Le Pro 3 Elite — the drive should mount. On the Le 1 and the Le Pro 3 AI Edition the sources disagree on OTG, so the drive mounting is the test. On the Le 1 Pro, the Le Max Pro and the Le S3 the sources say No, so the drive will not mount — use Method 3 instead:

  1. Plug in the USB drive with an OTG adapter. On all eleven that is a USB-C OTG adapter, or a USB-C flash drive plugged straight in, with the OTG wiring inside the adapter — a plain sync cable is the wrong cable, it connects the phone to a computer, which is the opposite direction. A notification should appear saying the USB storage was added; tap it to open the drive. If nothing appears, check Settings > Storage for the drive — and if the drive never shows up, the phone does not host it, and Method 3 is the route.
  2. Open File Manager and confirm the USB drive shows up under storage devices. EUI ships a File Manager app — the Le S3 user manual lists it in its contents — so open File Manager on your unit.
  3. Go to Internal storage, DCIM, Camera, where your camera photos live. On the six where this method should work, the photos are the 21 MP shots from the rear camera on the Le Max, Le 2 Pro and Le Max 2, the 16 MP shots on the Le 2, Le Pro 3 and Le Pro 3 Elite, plus whatever image files sit in the folders you pick.
  4. Select the photos (long-press the first, tap the rest, or select all). Tap Copy, then select the USB drive, and wait for the copy to finish — don't unplug the drive until the file manager says it's done. Eject the drive from the notification or from Settings > Storage before unplugging it. Use Copy, not Move: Move deletes the originals as it goes, so a bumped cable halfway through loses photos.

This works fine for a one-off copy, if the drive mounts at all. Its limits are the reason a backup app exists on the one phone where SnapDisk runs: you pick files one by one, there is no progress detail beyond a spinner, no resume if you unplug mid-copy, no verification that every file actually arrived, and you have to repeat the whole manual selection next time photos pile up. And it is proven on six of the eleven — on the Le 1 Pro, the Le Max Pro and the Le S3 the drive will not mount at all, and on the Le 1 and the Le Pro 3 AI Edition the mounting is the test.

Method 3: through a computer (the reliable route)

If a PC or Mac is handy, this is the route to trust: plug the LeEco phone into the computer with its USB cable, tap the USB notification and choose File transfer — and drag the DCIM folder onto the USB drive. This works on every covered model, with no Android-version question and no OTG question at all: the computer reads the phone as storage, and the drive plugs into the computer. It is also the only phone-to-drive route for the Le 1 Pro, the Le Max Pro and the Le S3, where the sources say the drive will not mount on the phone itself — and the route for a Le 1 or a Le Pro 3 AI Edition if the drive never mounts on your unit. It is also the route to use before flashing a custom ROM on a Le Pro 3, since that install wipes the phone. Its only cost is the second device in between: if the phone and the drive are all you have, Method 2 is the route on the six where the drive mounts, or Method 4 on the one model that takes a card.

Method 4: the microSD card reader route (works on one of eleven)

Only one covered LeEco model takes a microSD card — the Le Pro 3 AI Edition, with no ceiling stated in any source found — and the card-reader route needs no OTG, no computer connection to the phone, and no app: 1. Power the phone off and remove the microSD card. 2. Put the card in a USB card reader and plug the reader into a computer, or into a USB drive with a built-in card slot. 3. Copy the DCIM folder from the card to the drive. 4. Put the card back and power the phone on. This is the same route the old phone manuals describe — remove the memory card, place it in a card reader, and let the reader transfer the pictures — and it works identically for a phone card. Two warnings: if the card holds photos the phone has not yet written to it, or photos stored on the phone's internal storage rather than the card, those photos are not on the card — check where your photos live first, in the camera app's storage setting or in File Manager. And the Le Max Pro may or may not take a card at all: Gadgets360 says no expandable storage, MobileGizmo lists a microSD slot up to 64 GB on the second SIM slot — so on that model, check your unit's SIM tray before counting on this route. Unlike Shiftphone, where the route is proven on all four, and unlike Volla, where it is proven on six of seven, only one of eleven LeEco models takes a card — so for this brand the card-reader route is the exception, not the fallback.

Method 5: Google Photos, or the cloud — not phone-to-USB plain files

LeEco offers no backup tool to a USB drive at all — no LeEco-specific backup advice turned up in any source beyond a computer copy, its own cloud, or Google Photos — so the stock options are the clouds, and none of them writes your photos as plain files to a USB drive automatically. 1. LeCloud was the backup LeEco bundled with its phones — 5 TB of cloud storage and unlimited storage for photos and videos — but LeCloud's personal cloud storage ended in June 2017, so that route is gone. 2. Google Photos is the backup on the models that shipped with Google services: turn backup on in the Photos app and your photos save to your Google Account — but that is a cloud backup, not a USB copy, and the Storage saver setting compresses photos. The China-market Le 1 ships without Google Mobile services, so Google Photos may not be on your unit at all. None of them is a one-tap way to copy your camera roll to a drive as plain files. All of them work fine for what they are. Their limit, for photos specifically: none of them gives you a folder of plain photo files on a USB drive you can plug into any computer and open. If what you want is a copy of your photos you can open anywhere, Method 2, 3 or 4 is the route — that is the gap this article fills, as of November 19, 2026.

What this does not do

  • It does not back up your settings or your contacts. SnapDisk copies photos, videos, and any files you pick — the files themselves, exactly as they are. App settings, call logs, texts, and your accounts stay with your phone and your LeEco account. For those, Android's built-in backup is the tool — it backs up personal settings to Google's servers with a Google account — not SnapDisk.
  • It does not delete photos from your phone after copying. Deleting is always your choice, after you check the copy on the drive. SnapDisk never deletes originals — it only copies.
  • It does not install on stock LeEco firmware at all. All eleven covered models run Android 6.0.1 or older, below SnapDisk's 7.0 floor. Only a Le Pro 3 running LineageOS 14.1 clears it — and flashing that ROM wipes the phone.
  • It does not work if your phone does not host a drive. On the Le 1 Pro, the Le Max Pro and the Le S3 the sources say No to OTG, so if the drive never mounts on your unit, no backup app of any kind can copy your photos straight to a USB drive on it. If the drive never mounts, that settles it for your unit — use Method 3 instead.
  • It does not back up photos from apps that hide them. Some apps keep photos in private folders SnapDisk cannot read. Those stay on the phone — check each app's own export or share option.
  • It does not compress your photos. It copies the original files byte-for-byte, so the copy is the same size as the original. On the Le Max, Le 2 Pro and Le Max 2, with their 21 MP cameras, that is real storage on the drive — bring a drive with room.

What to avoid

  • Don't move files instead of copying them. The file manager's Move deletes the original as it goes. Copy first, check the copy on the drive, and only then delete the originals from the phone if you need the space.
  • Don't unplug the drive until the copy is done. If the copy is still running — SnapDisk shows progress, speed and ETA — unplugging leaves half-copied files. Wait for it to finish, then eject the drive from the notification or from Settings > Storage before unplugging it.
  • Don't buy a micro-USB adapter. All eleven covered LeEco models take USB Type-C — there is no micro-USB phone in this article at all. A micro-USB adapter does not fit any of them.
  • Don't buy a drive expecting it to mount on the Le 1 Pro, the Le Max Pro or the Le S3. The sources say No to OTG on all three, so a no-mount settles it for your unit. Use Method 3 instead.
  • Don't buy a drive expecting SnapDisk to install on stock firmware. No stock LeEco phone clears Android 7.0 — the highest runs Android 6.0.1 — so the APK will not install as the phone shipped. The only documented exception is a Le Pro 3 on LineageOS 14.1.
  • Don't flash a custom ROM without backing up first. The LineageOS 14.1 install on the Le Pro 3 wipes the phone completely — copy your photos to a computer with Method 3 before you start, or the backup you wanted is the thing you lose.
  • Don't count on LeCloud. LeEco's own cloud storage ended its personal service in June 2017 — the 5 TB that came with the phones buys nothing today.
  • Don't buy a card for the Le Pro 3 AI Edition on a ceiling figure. No source states a card ceiling for it at all — check your unit's slot before buying a large card.
  • Don't let one folder hold every photo. SnapDisk copies oldest-first, and the copy is the same size as the original, so a full camera roll on a phone with a 21 MP camera — the Le Max, Le 2 Pro and Le Max 2 — fills a small drive fast. Bring a drive with room, or back up in batches and check the copy before deleting anything.

Rule of thumb: if you have to pick the files yourself, it isn't a backup — it's a copy. A backup finds your photos, copies them all, and tells you when it's done. On a LeEco phone the honest position is harsher than on most brands in this series: no stock LeEco phone runs SnapDisk at all, so the one-tap backup exists only on a Le Pro 3 that has been flashed to LineageOS 14.1 — everywhere else the computer copy or the file-manager copy is the backup, and only the Le Pro 3 AI Edition has a card-reader route at all.
